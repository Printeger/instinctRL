# 用配对短训检验管道恢复课程

首个同权重后向对照救回 1/32。该树干轨迹在共同活体窗多下发 0.145 m 同侧横移，实际横移增加 0.054 m，最小球面净空增加 0.118 m。第二个开发随机流的七组各 224 条初始轨迹，两臂均为 5/224 接触且具体轨迹相同。管道恢复为 8/8、0.724 m，静漂均值 4.89 mm，远离跟踪相同。后向跟踪 RMSE 增加 0.00208 m/s。本轮短训两臂都用备选执行，保留同权重消融和原第三轮组合。 [首个复算](REARPAIR-01.json) · [广谱对照](MECHANISM-01.json)

两臂都从同一第三轮 `u768` 载入 actor、critic、Adam 和绝对计数。训练开始时从同一新种子建立 Python、NumPy、Torch CPU/CUDA、课程及 PPO 排序流。每臂用 16 次扰动课程更新及 16 次普通回放更新，共 16,384 新增步，保存 16 次及 32 次更新节点。扰动阶段的周期为 192 步，唯一干预是管道 lane 的前飞指令从 100 步延至 144 步，其余课程、奖励、学习率、噪声、延迟及丢帧保持配对。此干预的假设是来物开始远离后，训练可见更多有非零操作者指令的恢复时刻。

球龄随每条轨迹重置，课程时钟按整个阶段前进。覆盖从真实轨迹复算，分别检查至少四条活跃管道 lane 的可见逼近、至少两条 lane 相对控制臂各增加十步有效恢复机会、持续实际前向下发，以及三个停放来物的 lane 仍有静止窗口。前述时间延长也减少静止训练时长。下游行为比较统一用相同新开发场景与命令，涵盖管道恢复、静止漂移、普通非零指令与接触。

同执行候选的恢复率增加一条或平均固定窗进度增加 0.05 m，且无新增接触，支持进入更长有限微调。若真实覆盖增加、两臂护栏维持且观察到方向一致但较小的收益，可用有限更新检验后续对进度的影响。若收益主要来自零令或存活样本计分、实际覆盖没有增加，或新增接触/静漂越过 5 mm 配对护栏，调整课程或保留原配方。所有轨迹计入固定分母，首接触计为联合失败。
