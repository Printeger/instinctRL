# 在普通回放上保留可行的指令增益

单程来物的有限组把扰动阶段的实际恢复和前向下发提高到 387、289 步。+128 端点却在树干新增两次零指令前向接触，管道恢复从同场起点的 0.704 m 降到 0.635 m。折返与单程 +128 的两次评价具有相同初始位姿、球位置、感测参考点与指令，重复的 `u768` 各初始轨迹的接触、跟踪、恢复和静漂均一致。 [物理配对复算](CROSS-COURSE-U896.json) · [单程有限确认](CHECK-FINE-SINGLE-PASS.json)

普通管道的 960 步里，ICS 缩放全为 1，侧让与回切没有接管。单程链的 +32 到 +128，平均 actor 增益 0.836→0.781，真实轴向速度 0.203→0.190 m/s，最小净空均值约 1.126 m。恢复窗中还存在 ICS 缩放，普通通行降速提供了更干净的学习对照。原配方仅在扰动阶段启用通行增益辅助，普通阶段只保留零指令先验。

本轮继续单程课程，保持动作执行和扰动阶段训练代码。只在普通回放用当前有效 LiDAR、测量时序、IMU 和非零指令选择清晰的前向锥束。沿用既有 1.9 m 净空和至少 8 条可靠锥束条件。仅惩罚低于 0.855 的平均增益，权重 16，目标依据本开发流起点普通管道均值 0.854 取整。验证 64 更新，其中 16 次扰动、48 次普通回放。以既有单程有限组的同种子 +64 节点作同量控制，并与同执行 `u768` 评价。此辅助不会绕过 governor 或 ICS，也未向 actor 新增输入。

先核对普通回放命中掩码的实际数量。若普通管道平均增益相对同量控制增加至少 0.025，且具有同向的实际前进和恢复结果，同时无新增接触，持有原跟踪和静漂护栏，则支持把增益保留与单程课程一起带入长训。若掩码几乎无覆盖、只有增益变动而没有实际下发和位移变化，或出现新的零指令接触，重新检查门控和共享网络的权衡。
