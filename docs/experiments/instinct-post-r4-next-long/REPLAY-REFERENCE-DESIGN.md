# 普通回放用冻结策略保持已学动作

增益短训的普通回放中有 4,492/24,576 个优化样本命中清晰通行掩码。实际普通开口管道的同量控制与增益组 `alpha` 为 0.7810 与 0.7826，进度为 2.2780 与 2.2789 m，共同起点为 2.4800 m。固定清晰阈值下的单一增益目标未传到物理通行，接触也未守住起点护栏。 [训练命中](REPLAY-GAIN-TRAINING.json) · [同量三臂](CHECK-REPLAY-GAIN.json)

保持单程管道课程、16 次扰动训练、48 次普通回放、起点、种子和执行。普通阶段在同一批获批 actor 观测上运行冻结 `u768`，用其平均增益及三个残差作为动作保留目标。残差差值按 0.1 归一化，四个分量的平方差权重为 32。扰动阶段沿用原 PPO 辅助，冻结策略没有梯度，实际采样和执行始终用候选。冻结策略在每段均从同一原点读取，构建时保护 Torch CPU RNG；同链续段继续按已保存 RNG 严格恢复。

与已闭合的单程有限组 +64、相同执行的 `u768` 三臂配对。入场依据是普通管道平均增益相对同量控制增加至少 0.035，实际通行进度增加至少 0.10 m，管道联合恢复和固定窗进度无实质退化。同时检查逐轨迹新增接触、普通跟踪和 5 mm 静漂护栏。若保留项能移除已观察到的剂量退化，并保持课程实测的恢复机会，长训检验这种约束能否在持续回放及重复目标暴露后留住双重收益。若动作目标确实命中而仍出现新增接触，先查动作残差、实际下发及训练进度的共同变化。
