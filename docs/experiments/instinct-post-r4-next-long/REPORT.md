# 第三轮之后的避让与恢复续训

任务 `instinctrl-post-r4-next-long`。以第三轮 `u768`、25° LiDAR 标定与裁零后转向为仿真对照。旧合格模型继续用于 R6 和物理回归，前轮权重及历史原件保留。actor 的输入仍为获批 LiDAR、IMU、测量历史、有效性、时间与操作者指令。控制器的候选动作通过既有 governor、ICS 与飞控。用于归因的位置、速度、球面距离和接触真值都来自独立的记录和评价路径。
