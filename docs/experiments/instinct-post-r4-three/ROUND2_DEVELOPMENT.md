# 第二轮开发问题

第一轮 `u896` 两段关闭并核验了分段权重、计数和 RNG。开发配对中，普通前进在四布局都增加，树干和街道的普通跟踪 RMSE 改善。后向仍 24/32，非零指令接触从 0/88 到 1/88，管道联合恢复从 8/8 到 7/8。PPO 配方给出了普通通行收益，同时留下响应时间和恢复取舍。 [第一轮分段复核](FORMAL-R1-TRAINING-AUDIT.json) · [开发逐布局配对](CHECK-FORMAL-R1-RECOMPUTED.json)

0.45 m/s 的固定权重臂救回的后向轨迹来自四布局重复的两个较早回波方向。离线射线复算在 30° 逐条复得旧后向 32 条首次命中，25° 预测早 6–9 个采样步，28° 预测早 2–3 步。离线几何据此只用来选角度。新物理三臂固定 `u640`、原 v2 动作、机体姿态、初态和来物，比较 30°、28°、25°。原 governor、ICS 和底层飞控的裁决保留，实际 raycast、ICS 和避让试算使用同一组校准后的射线。改角只在评价臂切换及其首帧重置前，按臂保存真实局部射线表。 [离线命中复算](MOUNT_GEOMETRY_REPLAY.json) · [同权重物理设计](MECHANISM-R2-SPEC.json)

若实际更早送达能降低正常后向接触，并保住前向、普通通行及静止，则用该标定与相同 `u640` 做配对短训。若仅有几何提前、动作或接触未改善，后向选路改查可执行斜向分配。若前后向出现取舍，按真实轨迹比较两个角度和 30°，再决定第二轮是否使用新标定。第三轮将据第二轮开发证据选择目标或课程，最终独评协议继续保留。
