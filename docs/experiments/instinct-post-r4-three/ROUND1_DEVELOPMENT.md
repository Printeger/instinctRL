# 第一轮开发选择

固定权重的正常来物对照中，原回切、0.30 m/s 方向臂、0.45 m/s 幅度臂的后向接触为 32/32、32/32、24/32。幅度臂前向接触为 3/64，非零指令接触为 0/88。它在四布局各救回两个局部方向相同的样本，四布局重复同侧先见回波条件。原回切到等权重方向臂，门洞和街道联合恢复分别从 0/8、2/8 升至 8/8、8/8，管道保持 8/8。方向臂与幅度臂的前向、普通通行和静止指标一致。 [固定权重配对](MECHANISM-R1-RECOMPUTED.json)

同机制 `u640`、`u656` 和 `u672` 的后向均为 24/32，前飞逼近接触依次为 0/32、1/32、3/32，联合恢复依次为 32/32、30/32、29/32。`u656` 管道恢复窗进度由 0.726 增至 0.768 m，同时门洞和树干退化。`u672` 接触总数少两条，主要来自悬停避让改善，并新增前飞接触。两短训节点的普通前进仍在相同机制起点的 97% 以上。Rebel 独立复算全部 18 份轨迹，指出前飞新接触与总接触下降的方向相反。 [短训配对](CHECK-SHORT-R1-RECOMPUTED.json)

下一短训保留同一个 `u640`、执行版本、课程与种子，仅改 actor 学习率 `3e-5 → 1e-5`。先检验前飞接触和联合恢复能否保住，随后比较普通通行、非零跟踪和静漂。反复扩量此前的更新幅度会混淆在固定权重下已成立的执行收益。后向剩余碰撞用于检验动作与回波的时间余量，训练对照继续保留全部失败。 [较小学习率短训](SHORT-R1-B-SPEC.json)
