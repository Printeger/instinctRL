# R4 后三轮研发

任务 `instinctrl-post-r4-three`。本轮授权来自用户的接续指令。三次正式 GPU 长训按轮间开发证据选择，第三次完成后执行统一独评，完成审查材料后停止。训练、仿真及同设备概率复核使用本地直接入口串行执行。系统分区实测容量须覆盖当前作业上限并留出 30 GiB。早期开发、零转换失败及部分训练均记录实际开销并保留原件。

## 接手判断

| 环节 | 已有证据与下一步 |
| --- | --- |
| LiDAR、IMU 与可观测性 | 后向首回波晚于前向，转机体对照也改变姿态。第 41、43、53、61 步分别是后向首个已有回波、侧让、紧急裁零和接触的中位数。均匀管道中沿轴运动的线索会退化，悬停漂移需独立测量。新对照记录测距见证、送达见证和测量年龄。 |
| 策略与动作替换 | 现有侧让覆盖采样动作，PPO 日志保留原样本。后向 32 条都触发，活跃横向下发无一超过 0.03 m/s。沿用 PPO 和旧目标扩量对该方向选择没有直接作用。 |
| Governor 与 ICS | 后向首次触发虽有 β=1，下发中位横向仅约 0.016 m/s。紧急状态会将任意方向裁零。回切同权重对照则证实恢复窗的实际进度与重新获得方向下发同步。 |
| 机体响应 | 后向管道实际横移中位约 0.020 m。要在同一个下发窗测横向指令积分与 PhysX 横移，区分时间余量、方向和动力学。 |
| 奖励和课程 | 1,024 次更新的正式配方只含 128 次目标场景更新。非零通行大体保住，街道恢复改善，管道少一条无接触轨迹达到恢复进度阈值，R6 连续跟踪和管道静漂退化。训练收益需通过同机制起点配对。训练资料只能按获批的奖励、critic、评价与日志用途使用真值。 |

接手证据见 [R4 后审查](../instinct-r4-recovery/REPORT.md) 与 [物理原件索引](../instinct-r4-recovery/MECHANISM_RESULTS.json)。

## 首轮开发顺序

先比较固定 `u640` 的后向 2×2 因子。共用来物路径、布局、机体姿态、初始状态、零指令和传感管线。方向因子在原触发步按 governor 和 ICS 实际能发出的横向分量选择方向，继续用原持时及回切。时间因子将轨迹速度从 0.42 降至 0.28 m/s，并相应延长行程时间。时间因子测响应余量，真实回波的时序与差分阈值也须复核。

Rebel 的复算确定先查方向。Inventor 的建议决定试算双侧和斜向实际下发。Hacker 指定复用 assay、训练与关闭入口，并提出同轨迹速度对照。Scientist 的复算决定冻结逐轨迹分母与连续进度，修正新留出的悬停重置随机流。Producer 的实测决定保留约 46 GiB 给七臂 R6 原件及末臂准入峰值，并逐次结算。

如果相同速度下横移和接触改善，先保留方向机制并检查正向恢复与普通运动。如果只有较慢组获益，把时余量或感测覆盖作为下一轮问题。如果仍无可执行横移，先复核候选动作空间和 ICS，避免用增加 PPO 更新代替执行诊断。真正短训起点、配方和种子随开发对照冻结。正式规模按短训实测给出，固定每轮端点。开发评价使用独立于最终测试的随机流。
