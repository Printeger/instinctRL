# 第一轮正式训练与评价

短验证发现方向选择只能解释部分静态现象，同最新回波的逼近与远离需要历史信息。本轮将这个发现缩成当前真实环境可检验的问题。在保持方法、飞控、actor 输入和原硬护栏的前提下，等量续训时增加既有合法 LiDAR 历史的时延与丢帧暴露，能否改善扰动下的停令表现并保留运动跟踪？更广的几何分布与有运动障碍的闭环不在现有登记协议覆盖范围内。

从同一 u640、同一训练随机流 `2026112201` 续训至 u768。原 64 更新保持不变，后 64 更新和历史原配方使用相同条件与 0.01 m 噪声，另加一帧延迟和每 24 步一次丢帧。两项组合为这一轮的唯一课程改动，结果只归因于组合。候选与冻结 u640 和历史原配方 u768 的同评价流 `569431406` 比较。这个流已在历史研究揭晓，结果为配对回归和机制证据。

完成 65,536 条训练转换、128 次 PPO 更新与五个 checkpoint。候选完整评价记录 193,600 条非训练转换。首要连续比较取 `S-delay-drop` 停令后 1–11 秒有效锚 MAE 和停令位移，另报告跟踪误差、净空与原有通过率。5 mm 为锚误差工程参考。一个续训随机流只提供条件性证据。
