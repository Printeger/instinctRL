# 第一轮接手开发

要回答的问题是，在当前飞控和安全层下，LiDAR/IMU 策略是否有沿管前进并抑制横向趋壁的动作空间。冻结 u640 在 R6 登记条件通过，管道 B0 资格只覆盖接线和场景身份。现有锚奖励试验未证实改进。 [R6 结项](../r6-direct-training/FINAL_R6_RESULTS.md) · [第三轮结项](../third-training/formal/REPORT.md)

候选包括方向选择性的局部避壁反应、用测距历史区分逼近和远离、以及用可辨的短时反馈尽早检测风险。先验证执行层是否保留轴向速度，再决定是否值得学习其中任何机制。局部信号与快速反馈的联系参考触角传感实验，迁移到 LiDAR 是本轮假设。 [Mongeau 等，2015](https://pubmed.ncbi.nlm.nih.gov/26026042/)

短验证复用当前 MID360 射线和 R6 的 ICS 额外 0.15 m 裕量。解析等截面方管的回波与管壁法向由解析几何给出。对每个姿态分别输入轴向、斜向和趋壁命令。宽管校验轴向可放行，前端面校验轴向会被限制。以零限速射线的横向凸包核对是否存在能绕过标量衰减的正轴向动作。旧评价的 0.80 m 几何下限和 ICS 的射线加裕判据分别报告。 [输入](INPUTS.json)

只有在目标场景存在可行输出、候选有可归因的学习目标且可在配对闭环中检查真实任务推进和安全护栏时，才使用用户授权的一轮训练。根据短验证结果决定下一阶段候选。管道解析原型与开环决策只用于设计。既有飞控、运行安全层、历史结果与冻结 runtime 保持原样。

## 设计迭代

首个有效探针显示原安全层可在 0.95 m 的居中样例放行纯轴向指令，斜向指令却被一并缩放。因此试验逐射线约束下的确定性分量修正。在同一快照用有限次投影削弱约束冲突最大的分量，再过原 ICS。额外比较偏心、不同航向、可见端面、回波局部缺失和全缺失。至少提高 0.05 m/s 的轴向输出才计为该样例的可测差异。逐项报告整向量指令误差、侧向分量和 0.1 s 匀速几何净空。回波缺失单列，全缺失时原型弃权。上述指标用于筛选，闭环安全或泛化需要后续独立证据。 [修正候选输入](SHADOW_INPUTS.json)

本轮结案前纳入用户补充的跨场景目标。管道代表几何退化。修正候选同时使用门洞、离散圆柱和移动面三个局部几何对照，作为室内狭口、林地或城市孤立障碍、相对运动的低成本检查。移动面在两组使用完全相同的最新扫描，同时用不同的测距历史区分逼近和远离。只对一瞬的方向选择有效的原型，无法据此支持跨场景训练。完全空旷场景不属于产品目标，观测全缺失仍用于检验弃权。
