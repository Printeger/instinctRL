若新开发对照未支持前向首拍规则，且 B 已通过全部验收，则安排 C 复验已通过的后向执行和原参考在线配方。C 的独立物理场景及种子保持上述冻结。R6 共用三个已锁定的控制原件，新增 C 终点臂。
