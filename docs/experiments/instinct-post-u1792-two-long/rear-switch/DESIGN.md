# 后向反侧斜退闭环对照

固定已接受的 `u1792` 和原镜像开发流。观察组中，后向第 25、30 条轨迹在旧同侧备选执行失败后分别第 49、48 步被非紧急裁零。两条当时都在向初选负侧运动。同一组已送达观测下，正侧斜退在裁零后的三个连续步均可通过原 governor 与 ICS。原测距逐步重算实际下发的最大绝对误差为 `2.98e−8 m/s`。这些预测沿原轨迹计算，改变动作后的惯性、净空及后续裁决需由闭环检验。 [限幅束与下发复算](../PIPE-AUTHORITY-01.json) · [关闭后的双轴与静止原件](../PIPE-PROBE-01.json)

两臂固定权重、触发、25°、指令、随机流、镜像条件、动作速度和急停。候选只在零指令后向、持续中的同侧斜退已尝试且仍不可下发、也未触发急停时，按轴向比例 1.4、2.2 试算反侧。通过原 governor 和 ICS 且反侧实际可下发投影大于 0.08 m/s 才允许换侧，每个选项至多换一次。前飞、静止负控全部纳入同一批固定分母。

至少救回一条目标后向轨迹且整批零新增接触，静止组零新增逃逸与急停，平均最大水平偏移增加不超过 5 mm。前飞联合恢复保持，管道固定窗均值退化不超过 0.03 m。达到这些条件后，换新镜像开发流确认，随后才用同执行短训比较实际学习增量。若反侧能下发但仍接触，检查反转惯性和共同存活窗实际位移。若动作在改变轨迹后就被裁零，优先改首发动作可行性或用可信回波测提前量。
