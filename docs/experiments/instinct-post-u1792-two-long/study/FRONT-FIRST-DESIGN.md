# 首发侧选的尺度检验

A 终点和同执行起点在前向新留出的一条树干轨迹同拍触发，来物见证距离同为 1.8646 m，首次都可完整下发。A 向负侧，起点向正侧。A 第 26 拍裁零，此时全局最小净空约 .778 m，来物见证扣余量仍约 1.189 m。原件保留全局最小值，具体限幅束待新开发采集。完整闭环只给 A 记一次新接触。偏侧连续项的解释与已录轨迹相符。 [A 轮冻结留出](HOLDOUT-A.json)

在新开发树干几何中预先生成镜像对，在原后向选宽侧基础上做一次同权重前向消融。现有触发、零指令、前向和近纯横向条件同时成立，双侧原 ICS 都允许完全下发且仅一侧活跃束集合为空，才首发选择空侧。保留原裁决、速度、有效性、时序和同侧备选。原留出只提供失效机制线索，测试和任何新训练使用单独冻结的场景流。

固定比较窗口覆盖前向树干、全布局普通通行、独立后向负控及静止。优先看固定初始轨迹无接触增加，以及首拍切换是否确实避开后续非紧急裁零。正式候选需要独立开发支持、在线短训和随后新冻结独评。原两条训练与其结果都保留，按原门槛判定。
