# 连续生成指令 110 秒开发验证

用相同 B 权重比较扫掠范围 v1 和 v2。v2 仅要求两段连续可靠的距离历史都显示异常快速收近，才让扫掠范围外的一束回波保留原径向限速。正前扫掠内、传感器历史缺失、急停条件仍走既有约束。62 s 中的门洞限速束离线几何复算里，321 个受限拍的单束估算有 204 个只在两个相邻区间之一表现为快速收近，114 个都表现为快速收近。该结果支持比较这两个条件。

保留前 42 s 的路线前缀、已知布局种子和横穿相位，之后以新生成种子 98177 接上连续输入。街道移动体改为约每 15 s 一次往返，移动持续穿过全部换向和停杆。统计每个首飞实际横穿时窗、最低净空、接触、提前终止和实际进展。将 episode 的正常时间上限设为 110.2 模拟秒，以覆盖 110 秒完整首飞。碰撞、高度和其他既有保护不变。此轮用来核对超过原 100 秒的运行与回放，后续正式留出仍需冻结新的场景与指令。

一次模拟器初始化，两臂共 70,400 个物理评价步，墙钟上限 1,800 s，payload 512 MiB。均不训练。
