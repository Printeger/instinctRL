# 管道实测管壁下的有限推进和制动

独立 Crazy 复验的管道轨迹 29 在第 880–975 拍有 9.6 秒连续可行低进展。91 个裁零拍的限制来自两块连续观测的纵向管壁。持续向墙执行 2.4 秒会越过安全净空，短时推进后制动有可验证的余量。 [原独立复验](../independent_far_crossing_reference/REPORT.md)

候选沿用 `v16` 和同一 B 权重。只在普通飞行及完整三帧稳定管壁证据下，逐拍验证当前请求的有限推进、待下发命令和制动余量。保持紧急制动及所有缺少管壁归属的原有约束。从近期已下发命令复算响应并限幅，避免为追赶当前命令而触发后续反向运动。候选先验证 0.60 秒，随后可以验证更短的 0.30 秒；实际下发后下一拍重新验证。

同输入比较采用第 58 批的几何、Crazy 指令、横穿时钟、扰动与松杆窗，变更只涉及普通状态下的管壁证书。固定对比管道轨迹 29 第 880–970 拍及轨迹 28 第 1023–1056 拍的实际沿令达标数、每拍原下发和物理净空。另按正式短程公式报告所有轨迹，包括移动后可行段数量的变化。 [独立预登记](../independent_tube_stopping/PLAN.md) [正式门槛](../long/GATES.json)
