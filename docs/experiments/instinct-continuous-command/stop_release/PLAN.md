# 松杆后结束旧逃逸的同权重对照

同 B 权重、五布局、物理种子和 HOVERPATH-01 候选配置。候选只在从移动切换到零令后的前三拍重新检查先前已启动的普通逃逸。四帧有足够共同有效回波，当前测距大于 0.85 m，观测未显示持续收近且 IMU 历史在限定范围内时，结束旧逃逸并恢复零令。新触发和测量显示仍有危险的窗口保留原保护。时序固定，下一拍重新读取当前指令和传感输入。

原有 110 s 输入中，走廊 lane 27 第 595 拍松杆后仍发出 19 拍非零速度，最大位移 0.641 m。室内 lane 2 第 1011 拍松杆后仍发出 18 拍非零速度，位移 0.669 m。预登记这两段及树林、管道、街道既有松杆窗口，两臂使用同一生成输入。另用 RANK-01 第 1079 拍的真实折返测距，CPU 核对当拍的近距离和收近会保留撤离。该样本用于单拍保护核对。

两臂记录安全停稳时间、最大漂移、全部实际接触、第一航段和 5 ms 净空。共 70,400 个 PhysX 评价步，单次初始化，工作负载上限 1,800 s，结果上限 512 MiB，系统盘保留 30 GiB。只用于开发评价。
