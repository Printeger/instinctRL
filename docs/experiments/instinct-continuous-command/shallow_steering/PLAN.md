# 浅角推进的同输入物理对照

固定 B `u2816`、第十份独立短回放的几何、32 路 Crazy 输入和横穿时钟。短回放中室内轨迹 6 的安全可行低进展时长达 9.4 秒，树林轨迹 11 达 7.7 秒。用同批已关闭的 `v10` 作对照，观测候选在当下指令方向上的实际进展、跟踪误差、恢复和完整的安全指标。 [对照结果](../independent_static_reference/REPORT.md)

候选先检查原下发进展及优先避让。仅当交付的三帧测距分别支持 actor 方向和浅角候选方向，且候选通过原 ICS 并保留至少六成指令方向分量时，才采用浅角选向。保留新拦截、已续接拦截、制动、排序避让和退让的优先级。`escape_shallow_steering` 记录每次实际采用。

CPU 闭环重渲染中，室内轨迹 6 的指定窗口低进展从 4.3 秒降至 1.1 秒，树林轨迹 11 从 7.7 秒降至 3.1 秒。先前接触轨迹的关键横穿时刻、原松杆窗口及独立街道最小净空窗口均保留作为反例。CPU 使用记录姿态和近似滞后模型，物理结果以本次原生回放为准。 [CPU 证据](CPU-WITNESSES.json)

所有 120 秒首飞、零接触和重置、五类最小物理净空 0.15 米、32 个预设松杆在 1.0 秒和 0.20 米内、室内过门过角各 8/8 均沿用。报告原件和同窗跟踪差异。达到继续筛选的条件后，另行用新的独立 Crazy 留出复验。
