# 底层垂向投影复核

首次 30 分钟原生评价中，四条走廊首飞随高度下降而触发重置。改用重力对齐保护后，200 秒配对仍有缓慢下降。第 26 路从第 10 秒起实测下降 0.104 米，已下发垂向量只能解释其中一部分，按速度控制器分解的垂直跟随残差为 −0.067 米。冻结的 32 路回放中按原转子响应计算，小倾角合力复核预计增加 0.037–0.063 米同状态等效高度。最大模型横向加速度变化 0.00210 米每二次方秒。该数值来自固定状态历史，需要由原生闭环验证。

`v51` 在底层转子适配器内使用现有飞控位置无关的垂向速度误差、姿态和实测分配矩阵。它将原垂向加速度目标与现有合力的垂向投影做差，仅补偿倾角不超过 5°、差值绝对值不超过 0.03 米每二次方秒、转子保有至少 2% 双侧余量的拍。分配不请求额外力矩，原转子迟滞、旋翼边界和受拒时的原发令均保留。保护层和 actor 继续接收原批准字段。逐策略拍记录实际获准的峰值补偿。

原生配对固定与 `NOVEL-104` 相同的 B `u2816`、32 路 200 秒 Crazy 指令、移动球、初始条件和五类窗口，单独增加底层投影。比较四条走廊的高度变化，重核实际横向运动、净空、碰撞、停令、跟踪与最新指令恢复。评价 64,000 步、一次显式初始化、零训练，墙钟 1,200 秒，载荷 512 MiB。 [首次长程结果](../long/REPORT.md) · [原 200 秒配对](../neutral_retry/REPORT.md) · [正式门槛](../long/GATES.json)
