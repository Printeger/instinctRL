# 零令时的侧向来物对照

复用 110 s 相同生成序列、种子、B 权重、场景和往返移动体。两臂均启用已通过 36 s 对照的提前撤离。候选只改零令遭遇侧向收近时既有逃逸的首拍选向。当前打杆为零，观测到可信的侧向收近，而且原选向离收近反向偏得较多时，试发沿观测退向的速度。经过原 governor 和 ICS 仍能有效退开才采用，保持期、紧急制动、其他指令和回切逻辑沿用对照。

第 83.4 s 的 lane 18 原件用于对照。CPU 影子估计复现第 811 拍可下发的反向收近方向，既有选向产生的是另一侧切向。要完整跑过该窗口，检查两臂实际接触、零令位移和再起步。候选须在往返环境减少可复现接触、保持其余布局接触和进展护栏。初段推进和横穿补充冻结机会窗，所有原件保留。

两臂共 70,400 个 PhysX 评价步，1,800 s 墙钟上限，512 MiB 结果上限，系统盘留足 30 GiB。未纳入训练。这轮仍用于开发。
