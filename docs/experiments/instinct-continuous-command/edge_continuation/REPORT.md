# 短时续绕配对结果

候选与有限边缘对照共完成 64 条 120 秒首飞、76,800 个实际评价步。各臂五类场景均零接触、零自动重置、零提前终止，32 个预设松杆窗口全部达标，室内门洞与转角分别通过 8/8。两臂最低净空同为 0.224953 m，出现在街道 lane 23 的 32.435 秒。候选树林最低净空由 0.485 m 降到 0.413 m，室内由 0.281 m 降到 0.273 m。工作负载完整落盘，直接入口清理超时并结束所有登记的进程。 [逐场景原件索引](RESULT.json)

短时延续实际下发 55 拍，其中室内 30 拍、树林 25 拍。按预登记的正式可行推进模型离线复算，树林最差连续慢速由 5.5 秒升到 9.4 秒，室内由 9.5 秒升到 9.8 秒。后续切向幅值配对沿用原有限边缘控制。 [复算输入和结果](../tangent_magnitude/CPU-WITNESSES.json) · [切向幅值配对](../tangent_magnitude/PLAN.md)
