# 在最新请求稳定时短时延续已确认侧绕

有限边缘侧绕在 same-stream 首臂救回室内过角。部分卡点仍有当前可下发的同侧速度，三帧远回波支持在相对位置改变后短时丢失。对已发生的侧绕及其后八拍做同状态复算，室内 lane 5、0 和树林 lane 8 分别还有 16、9、8 个额外可下发拍。固定原状态投影的最低包络净空为 0.292 m。 [前一轮配对](../finite_edge/PLAN.md)

候选在已下发的同侧动作得到新鲜回波支持后，最多延续八拍。智能体每拍重新读取最新请求并用全 ICS 核对该方向，速度须仍沿最新请求达到六成并有实际改善。用户指令较三帧历史变化超过 0.04 m/s、可靠回波进入 0.50 m、原请求解除强裁切、启用紧急制动或被移动体保护接管时结束延续。只在新鲜回波再次支持实际下发时更新时限。延续也要求新鲜时钟和低转动，侧向选择使用已批准的命令、已下发历史和测距。 [CPU 原件](CPU-WITNESSES.json)
