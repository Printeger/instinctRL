# 用相邻测距补足门框外侧回波的历史

候选仅调整低速 ICS 扫掠外的回波确认。当前可靠束会导致限速、视线距离请求路径超过 0.60 m 且原束缺少两段有效历史时，检查最近两个旧帧各自是否至少有两条邻束支持相同位置。横向差至多 0.045 m，沿请求方向差至多 0.095 m。保留路径内、已有直接收近证据和紧急停车的处理。只检查实际参与限幅的缺历史束。

室内交接之后，lane 0、1 在沿 +Y 横飞时仍反复被 −X 侧门框裁零。用候选的实际测距历史重放，在已登记转角前，补足历史可释放两条共四十九个原限幅拍。固定状态下 1.2 s 的离线物理投影最小净空超过 0.38 m。Lane 7 的横移全部通过，原 X 开始时横向位置尚未让开角沿，保留这组对照。全程核对新放行、转角与推进、每类接触、净空、松杆和已通过的街道撤离。

复用 B 权重、同一 32 路 Crazy 指令、初态、横穿和扰动。两臂各 120 s，76,800 个评价步，1,800 s 工作负载上限，512 MiB 输出上限，保留系统盘 30 GiB。
