# 同时复核横穿净空与已观测静态回波

独立 NOVEL-27 的街道 lane 19 在松杆开始时，原东斜向经过 governor 和 ICS，移动体预测间距为 0.865 m。沿拟下发方向扫掠时，已观测回波有 0.383 m 近点。该方向的离线物理包络净空为 0.142 m。第 1,068–1,072 拍原动作的投影继续降低，随后掉头并在后段接触。

仅在当前为零令、当前停驻路径已进入来物保护范围时，候选可尝试沿来物运动方向，以 0.2999 m/s 通过原 governor 和 ICS。现动作贴近已观测回波，或原选向失败且预测将接触时，才比较该动作。分别检查来物和实际观测点，再以两项中较小的净空决定能否改向。沿用移动体预测下限和既有收益门槛，静态回波门槛 0.39 m 包含 0.21 m 机体、0.15 m 余量和 0.03 m 采样间隔预算。缺测只沿用原有有界续持条件，延续已核准方向时保持原动作速度编码。

第 1,068–1,072 拍在原状态逐拍复算均经原保护层放行，投影净空约为 0.509–0.610 m。随后原件的同状态约束仍可能阻止后续移动，因此要用闭环复验安全。复放 NOVEL-27 的固定场景、32 路 Crazy 指令、扰动和 B 权重，检查原接触、五类净空和松杆。 [CPU 与原接触证据](CPU-WITNESSES.json)
