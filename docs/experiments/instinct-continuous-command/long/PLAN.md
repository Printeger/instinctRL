# 五类 30 分钟 Crazy 连续首飞

使用已通过独立短程物理评估与完整 R6 的同一 B 权重和执行配置。用新几何种子、独立的 32 个 Crazy 子种子、每条街道不同的横穿时刻和 5.0–5.2 s 的实际脉冲。每类至少 4 条独立首飞，每条从唯一初始重置后连续执行 1,800 秒。回放使用提交中冻结的完整时间戳指令，不读取真人序列。发车输入固定权重、配置、源码、命令、几何、扰动、窗口、门槛、资源与前驱回执。

CPU 在发车前逐路验证指令时钟与计划位置。每条在四个不同时段登记推进窗口，另登记两个计划上安全的松杆窗口。可行推进用当拍实测位置和速度复算，令当前请求执行 0.6 秒再停，沿 2.4 秒的实测环境与 0.35 秒响应曲线检查净空。危险介入和恢复用持续当前请求的独立扫掠。运行时按 5 ms 记录碰撞包络与移动体，实际首飞中断留下原件并保留窗口失败。街道需真实移动体限制扫掠且有回波见证才累计动态危险覆盖。危险结束后的恢复计到最新指令连续达标第五拍。 [冻结门槛](GATES.json)
