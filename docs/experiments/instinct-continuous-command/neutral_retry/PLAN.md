# 第二个零指令拍复证停车与交回

`v48` 叠加持续同向请求的两拍交回复证、已通过原墙面证明的切向余量和第二个零指令拍的停车复证。后者只复核刚从移动切到零且旧保护尚在占用的情况。先执行原停车逻辑，首个零指令拍保留原选择。下一拍仍为零时，对可关联的四帧回波和原发令历史重新证明；任一证据过期、存在当前闭合种子或原高优先级保护仍占用时，沿用原路径。 [持续请求复证](../recent_request_handoff/STEADY-REQUEST.md)

停车复证用四个固定响应点覆盖 0.25–0.45 秒连续区间。保留原 0.65 米球面余量、测量误差、方向锥、独立响应余量和至多一个旧发令拍。街道第 16 路首个零令拍第 156 拍不可证。第 157 拍的 CPU 三档下界最小 0.65215 米，对应停稳 0.6、0.8、0.9 秒，漂移 0.134、0.164、0.193 米。真实来物反例和街道第 17 路三档下发保持一致。证明适用于测得轨迹线与沿线反转。

已通过旧墙面切向证明和完整 ICS、沿令下发在 60.0%–60.5% 间的动作，尝试仍在原速度上限内的小幅切向补偿。当前可拟合来物阻止补偿。原推进评分仍用实测速率的 60%。走廊第 26 路三档响应均由 0/45 提升到 45/45；重复窗口的第 25 路由 16/31 提升到 31/31。已配对林道及来物反例保持下发一致，后续仍需原生核验。
