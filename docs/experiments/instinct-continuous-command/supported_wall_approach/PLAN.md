# 孤立墙面制动的 Crazy 配对复验

固定 B `u2816` 权重、N92 的五类场景、32 路 Crazy 指令、初始状态、横穿时刻和物理扰动。将 `v38` 换为 `v39`，在缺少对侧支持的普通墙面前保留原径向制动，继续允许有对侧支撑的墙面或独立验证的管道斜面进入现有有限路径检查。控制只使用已有测距、IMU、有效性、时间戳和命令历史。

连续 120 秒共 38,400 个评价步，最多 1,200 秒工作负载时间及 512 MiB 原件。检查 32/32 首飞、零接触及重置、至少 0.15 米净空、室内过门与过角及全部预设松杆窗。既有走廊第 26 路和街道第 22 路固定窗逐拍与 N92 配对。短程通过后使用新种子进行独立短程复验。
