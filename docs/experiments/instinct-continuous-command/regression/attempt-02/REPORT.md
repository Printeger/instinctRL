# v38 的完整 R6 回归失败

同一 B `u2816` 权重与冻结 `v38` 完成五个原任务和 16 个扰动块。实际执行 193,600 个评价步、21 次显式初始重置，期间零自动重置和训练步。原任务 S、T、X、Z 各 32/32，原任务 W 为 0/32。扰动块中 13 组各 32/32，`W-near`、`W-middle`、`W-far` 各 24/32，失败均为朝墙的 8 条轨迹。 [逐项结果与原件绑定](RESULT.json)

三组干净朝墙的最小测距从冻结 B 的 0.859 至 0.872 米降至 0.536 至 0.548 米，低于 0.80 米门槛。逐帧复算显示原径向保护已制动，有限路径检查反复移除了同一面墙的限幅回波。延迟丢帧的 `W-combined` 为 32/32，制动时约 0.10 秒的帧龄超过有限墙面检查的 0.04 秒上限。

配对跟踪误差、干净停令锚误差和有效覆盖的差值均为零。原任务及扰动墙组失败使总门槛未通过，`v38` 未进入 30 分钟验收。监督器在 2,670.26 秒关闭，回收退出超时的原生进程，回执记录退出码 `-15` 且无遗留。冻结 CPU 分析复算了全部 6,050 拍和 193,600 个评价步。 [资源记录](RESOURCE_LEDGER.json)

`v39` 在缺少对侧支撑的孤立墙前保留径向制动。真实归档回波复算撤销三组干净块中的 459 个放行拍。CPU 闭环样本保持走廊与管道的进展，并保持街道松杆样本。新的原生配对、独立短程和原始 R6 复验分别记录。 [修复证据](../../supported_wall_approach/CPU-WITNESSES.json)
