# 连续指令候选的完整 R6 回归

从独立仿真开发复验中选择通过的单一 B `u2816` 执行配置。锁定与后续 30 分钟验收完全相同的权重哈希、25° LiDAR、0.15 m 保护层余量和执行版本。沿用 B 历史完整 R6 的五个原任务、16 个扰动块、几何、种子、评分与配对对照。原评分及动作记录按冻结 CPU 入口复算，额外记录实际执行版本、安装角和 ICS 确认参数。

每个原任务和扰动块逐项通过，原侧墙的实际运动全部通过。沿用 B 工程比较门槛，最差跟踪 RMSE 增量至多 0.01 m/s，干净停令锚误差增量至多 5 mm，有效覆盖下降至多 0.02。任何冻结门槛未达成则继续保留全部原件。单次 193,600 个实际评价步，工作负载上限 3,600 s。原 B 的逐块证据配额与工作负载上限继续使用。系统盘剩余量接近原整轮配额的准入线，历史 B 原件约 4.2 GiB，本次单独预约 6 GiB payload 与 256 MiB 监督余量，保留系统盘 30 GiB。
