# 晚撤离对照未通过

两臂共 23,040 个物理评价步。v2 对照复现 lane 17、23 第 282 拍接触。候选在第 265、267 拍开始反向撤离，仍分别于第 279、280 拍接触。反向请求获得下发后约两个策略拍即被 ICS 裁零，机体尚来不及移出扫掠路径。晚撤离分支拒绝。 [原件、回执及复算](RESULT.json)

两条影子回放各 34 拍，每拍的原 ICS 缩放均复算匹配，测距见证最大差不超过 4 μm。第 254 拍已观察到斜向持续收近，原 governor/ICS 在两条轨迹均允许反向约 −0.30 m/s。第 268 拍时两条反向候选均归零。下一轮只尝试在该时间窗提前撤离。 [提前撤离方案](../early/PLAN.md)
