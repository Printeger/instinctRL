# 横穿回程时的恢复动作对照

110 s 两个配置各有 3/8 街道首飞接触，其中 lane 17、23 同在第 282 拍。原 actor 输出仍接近纯前向跟踪。取 262–277 拍的实测位置、移动体与冻结网格回算历史回波，测距见证最大复算差不超过 0.000004 m。两条失败轨迹在恢复层重新加速时已有连贯斜向收近，原方向门槛仍允许恢复动作。仅改恢复路径。若当前指令受限、恢复路径原本有权尝试、同时 LiDAR 检测到前侧连贯收近，候选试发沿当前指令反向的有限撤离。试发须通过原 governor/ICS，最多保持 1.5 s。无法下发撤离时选零目标速度，现有全方向紧急制动仍可裁零。

固定 B 权重和 110 s 的相同布局、种子、指令、往返移动体与时钟实现。只运行其中前 36 s，涵盖第 282 拍的可复现回程接触。对照为此前的 v2。两臂各重新跑整个前缀，记录当前原指令、恢复/撤离实际动作和最小净空。判据为两条已知失效都消失、没有新增接触或自动重置、常规通行未出现新的长时间停滞。较晚发生的零令逃逸失效需要另行复现。

共 23,040 个实际评价步，单次初始化，1200 s 墙钟和 512 MiB 原件上限，维持 30 GiB 系统盘余量。无训练。
