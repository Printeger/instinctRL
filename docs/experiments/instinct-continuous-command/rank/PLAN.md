# 横穿物折返后的撤离方向对照

同 B 权重、110 s Crazy Command Generator、五布局和物理种子。两臂均使用已验证对照的零令保持与近险后回中暂缓。候选只在近险等待期间出现新的有杆逃逸、近处回波连续两段确实收近、过去下发较小时，比较原逃逸方向、沿收近反向、逆当前指令三种经原 governor 和 ICS 可下发的速度。依据两段相对回波点的运动，计算前 1.6 s 的最小相对分离。当原选向落入近距且存在显著改善时才更换方向。换向后的已有保持期内暂不混入向前增益。

REARM-01 街道 lane 23 第 1078 拍的新逃逸，原分支速度约 (+0.165, −0.251) m/s，向横穿平面推进。原件测距重建下的同状态影子给出原选向、径向退避及逆当前命令的预测最近回波距离约 0.135、0.454、0.473 m，三种均可下发。物理配对验证实际接触、5 ms 净空、介入后最新命令的恢复，以及其他布局安全与推进。

两臂共 70,400 个 PhysX 评价步，单次初始化，工作负载上限 1,800 s，结果上限 512 MiB，保留 30 GiB 系统空间。使用相同的全量命令和原始证据格式。只用于开发评价。
