# 折返选向的 110 秒物理结果

两臂 64 条首飞均飞满 110 s，零接触、零重置，共 70,400 个 PhysX 评价步。第 1078 拍的候选把街道 lane 23 实际下发的轴向速度从 +0.165 m/s 改为 −0.300 m/s。旧折返窗口的最小 5 ms 包络净空由 −0.05065 m 提升为 +0.17099 m。五个预登记推进窗口逐类与原配置一致。 [逐布局结果与原件](RESULT.json)

整段最小包络净空仍是 lane 23 更早一趟横穿的 −0.01824 m，发生于第 106.035 s。另有 lane 19 第 104.160 s 的 0.02995 m。两条接近都由较早的零令逃逸改变停位。新一轮在同一输入首拍复核曲面回波，再用实测 5 ms 净空判断它是否减少这种进入。 [零令曲面方案](../curved/PLAN.md)
