# 持续反向撤离的指令交回配对

`LONG-01` 的室内第 1 路在第 3770 拍转令后启动反向撤离。反向命令通过完整限幅，随后沿既有计数保持到第 3784 拍。该处实际几何对有限推进和持续推进均留有空间。第 3776 拍起，现有四帧静态一致性证明及前向扫描均支持新令再次推进。 [CPU 原件](CPU-WITNESSES.json)

`v43` 在 `v42` 上逐拍复核已持续的普通撤离。新令需稳定，目标通过完整 ICS，且带命令响应与安装余量的 2.4 秒局部路径可证。远处逼近回波、既有横穿处理和其他高优先级保护均保留。两个连续当拍证明通过才结束撤离。原停驻处调用同一四帧检查，仍要求当拍指令为零。

| 目标 | 达沿令速度六成的拍数 | 对照 → 候选模型最小净空 |
|---|---:|---:|
| 室内 1，记录姿态，0.35 秒响应 | 2 → 10 | 0.666 → 0.847 米 |
| 室内 1，记录姿态，0.45 秒响应 | 0 → 8 | 0.691 → 0.865 米 |

两个实测来物和一个近墙反例的下发与位移逐拍相同。对长程已记录的前 750 秒筛出 184 个可能适用普通交回的时刻，其中 2 个直接跟令会低于冻结净空。测距重建中，两拍的原完整 ICS 均将候选速度拦为零。 [带哈希的证据](CPU-WITNESSES.json)

原生开发配对预登记 `NOVEL-99`。在完成 `NOVEL-98` 的独立安全修复配对后，以 `v43`、B `u2816` 和 `LONG-01` 完全相同的五类 32 路输入重放初始 420 秒。共 134,400 个评价步、一个显式初始重置、零训练，工作负载上限 2,100 秒，载荷上限 512 MiB。比较原横穿失败窗口、三个普通避让交回窗口、三个静态撤离窗口，以及其他轨迹的 5 ms 净空、停杆、门角和持续低进展。正式 30 分钟的冻结门槛在此开发配对中作为核对依据。 [对照输入](../long/R6-DIRECT-INSTINCT-GPU-COMMAND-LONG-01-inputs.json) [原正式门槛](../long/GATES.json)
