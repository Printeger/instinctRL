# 新场景与独立生成指令的 120 秒开发复验

冻结同一份 B 权重和选中的单一执行配置。依据 110 s 松杆对照的安全和漂移结果确定执行版本。32 条首飞使用各自独立的 Crazy Command Generator 派生种子，场景种子与指令根种子独立。室内使用已经验证过的延后横移前缀。五类场景各至少四条，初始位置和绕向沿用既有 R6 对种子与 lane 的抽样，街道八条使用独立的首次横穿中心时刻。第 5.0–5.2 s 施加来自现有 R6 物理入口的 0.5 m/s² 脉冲扰动，按 lane 分布方向，保存 40 个实际物理拍的力与时钟。全程记录实际接触、首飞、5 ms 净空、停止和推进。

开发净空检查值为 0.15 m，逐类记录接触、重置和中断，保留过门、过角、推进和停止的原始轨迹。本轮用来筛查新组合，随后正式场景、扰动和生成种子另行冻结。单一候选 38,400 个 PhysX 评价步。工作负载上限 1,200 s，512 MiB 结果上限，系统盘保留 30 GiB。
