# 横穿物刚折返时的同权重配对

复用 NOVEL-01 的 32 个独立 Crazy Command Generator 流、B 权重、五布局、横穿相位和实测脉冲。两臂均使用松杆释放配置。候选只在零令选向的曲面形状稳定、四帧匀速拟合不成立、较早一段运动方向与最新方向相反，并且最新两段一致收近时，用这两段估计折返后的运动。现有动作核对按同样的预测距离、已准许速度和保护规则选择方向。

街道 lane 22 第 144 拍新逃逸时，四帧轨迹拟合误差 0.031 m，最新两段近同向，上一段相反。最近两段模型下，原候选方向的预测表面距离 −0.264 m，原位 0.325 m，对侧切向约 1.017 m。该切向在同一帧能通过原 ICS。Lane 18 第 677 拍的接触首先来自非零令逃逸，作为分开归因的案例保留。

两臂各 120 s，共 76,800 个 PhysX 评价步，单次初始化，工作负载上限 1,800 s，结果上限 512 MiB，系统盘保留 30 GiB。逐类记录实际暴露、零令、接触、5 ms 净空及推进。用于开发配对。
