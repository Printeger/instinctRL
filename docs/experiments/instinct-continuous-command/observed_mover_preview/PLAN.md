# 接近来物的短时避让配对

`v56` 在同输入消除两处接触，街道第 17 路第 91.600 秒的物理净空仍为 0.100 米。实收测距在第 883 拍已确认来物接近。当时按原下发继续的 1 秒扫掠余量约 0.332 米。更早的两处提示虽让这个保守短模型低于 0.36 米，按测得转向外推的原下发净空仍在 0.57 米以上。把这些提示直接作避让入口会改变后续站位，CPU 较早启动对照的净空低至 0.020 米。 [原生对照](../measured_curve_approach/REPORT.md)

`v57` 只在连续接近、1 秒原下发余量低于 0.36 米，且由已测变化建立的延长投影也低于 0.15 米时考察新选向。短模型覆盖 1.05 米每二次方秒的各向加速度，含三档指令响应与三档队列。起步仍需 0.39 米短余量、实测静态扫掠和完整 ICS 复核，首拍速度增量至多 0.30 米每秒。延长投影只用来从短时已验证的方向中选向，要求比原下发至少增加 0.08 米且达到 0.12 米。之后逐拍以最新测距重证并保留旧控制优先级，最长十拍。

固定 N108/N111 同一几何、全套 32 路 Crazy Command Generator 序列、脉冲、停车窗及 B `u2816`。配对共 38,400 个评价步、零训练，逐路核对第 17 路最低净空、第 20 和 22 路既有修复、松杆、推进、恢复和行为审核。延长投影门槛仅限候选选向。原有短程物理净空和正式验收要求继续适用。 [正式阈值](../long/GATES.json)
