# 横穿前扩大可停留净空的同权重配对

对照保持 NOVEL-04 的时间对齐配置。候选仍以相同测距拟合和动作预估处理会相交的下发。当原下发继续执行预计安全、立即停留却预计离来物不足 0.36 m 时，只允许加大已经在执行的横向撤离。原撤离分量须至少 0.12 m/s，替代下发沿同方向增加至少 0.04 m/s，预计改善至少 0.04 m。现有 ICS 与全方向紧急停止继续生效。此条件不发出反向撤离。

原换向窗在 NOVEL-04 候选达成零接触，但约第 98 拍最小包络净空仍低于 0.15 m。固定轨迹复算在第 64–66 拍和第 73–84 拍可提前加强已有 −X 撤离。评价记录第 64 拍的可下发处置、换向窗逐 5 ms 净空、32 条首飞的全部接触和重置，并跨五布局复算先锋窗口和松杆。其余两处原晚段接触也保留在回归范围内。 [固定输入 CPU 证据](CPU-WITNESSES.json)

复用 B 权重、32 路仿真 Crazy 指令、横穿相位、初态和扰动。两臂各 120 秒，76,800 个评价转换，1,800 秒工作负载上限、512 MiB payload，保留系统盘 30 GiB。用于开发配对。
