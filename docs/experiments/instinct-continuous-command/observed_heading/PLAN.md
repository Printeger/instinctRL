# 实测方向和横穿后按拍恢复的同输入对照

固定 B `u2816`、几何、32 路 Crazy 输入和横穿时钟，用已关闭的浅角控制 `v11` 作对照。原短回放室内跟踪误差已全部达标，走廊仍有最长 5.7 秒的可行低进展，街道跟踪误差 0/8。 [同批对照](../shallow_steering/REPORT.md)

静态方向候选各自需要三帧测距支持、原 ICS 通过及至少六成沿当前指令方向分量。已有主动避让、制动、紧急、交接和拦截优先。新分支在原浅角逻辑没有出手且当前为普通控制时试用，保留原来的最终检查。在走廊四条代表窗，CPU 冻结 actor 闭环的最长低进展从 4.5–5.7 秒缩到 0.2 秒，候选的预测最小净空为 0.388 米。 [CPU 证据](CPU-WITNESSES.json)

有可靠来物拟合时，只有连续两拍证明当前 actor 方向留出足够的扫掠、停稳余量与旧指令残留距离，才在原拦截裁决后让该拍执行最新指令。保留原避让的计时和冷却，下一拍重新证明。两批街道轨迹 19 的局部 CPU 复算分别把最长可行低进展从 3.9 和 3.0 秒缩到 1.8 和 1.3 秒。先前接触和预设松杆窗保留作反例。两项行为各有逐拍记录。 [CPU 证据](CPU-WITNESSES.json)
