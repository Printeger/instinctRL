# 换令时复核静态斜向退避

街道第 22 路第 535 拍转向后，`v50` 和 `v51` 都立即下发与当前指令相反的退避，持续 15 拍。两份实测历史中的六条触发射线、以及各自 15 条和 14 条全分辨率接近射线，均可关联至同一三帧静态立面。可见运动体正在远离。有限请求和持续请求的物理复算均通过。

`v52` 在新触发斜向退避、近期指令显著转向时保留原指令动作，前提是完整 ICS 允许、四帧方向覆盖及有限路径合法、所有触发或接近射线都能关联到实际观测的静态面，且无拟合接近来物。实测动态优先级仍由原流程处理。这条复核使用原传感历史、时间、IMU 和发令历史。任何未归属的触发射线均保留原退避。

三档响应的 CPU 配对中，实测模型连续五拍达进展线的起点由 557、558、560 提前至 538、545、545，候选最差净空 0.887 米。两处实际动态接近对照仍拒绝交回。根据 `v51` 的短程净空及停杆失败，原生对照选用 `NOVEL-104` 的 `v50`，冻结 B `u2816`、相同五类布局和原 Crazy 指令的前 120 秒，单独启用本轮静态复核。重点记录第 535 拍附近的下发、进展、5 毫秒净空，以及早期真正来物对照。评价 38,400 步、一次显式初始化、零训练，墙钟 1,200 秒，载荷 512 MiB。 [配对对照](../front_wall_handoff/REPORT.md) · [垂向补偿结果](../collective_projection/REPORT.md) · [正式门槛](../long/GATES.json)
