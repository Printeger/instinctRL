# 仿真长期验收准备

本阶段按用户最新决定使用 crazy command generator。每份输入保留生成器版本、种子、命令时间戳和 SHA-256。用于调参的场景、前缀、指令和扰动组合属于开发集。拟将每类至少 3 组独立的新布局和生成种子放在同一候选配置下，每组首飞连续 1,800 模拟秒。走廊与管道分别计，以便识别其中一个掩盖另一个的问题。开发使用的组合不得充当正式留出。

首次正式运行前将同时冻结以下内容。

- 每个组合的场景几何、机体与传感器版本、初态、生成器配置、全量命令和扰动。场景与指令各有独立种子，飞行中保持历史、动力学和策略连续。
- 室内门洞与转角、树林式障碍、街道横穿、走廊与管道的有效危险类别和每类最低覆盖。用冻结的场景时序和实测空间关系判断实际暴露，提前终止或因持续停止错过的覆盖保留为失败。
- 各项通过阈值。接触、坠落、失控、提前终止和自动重置均要求零。物理净空基于验证过的机体碰撞包络和场景边界。安全可行段的跟踪误差和进度单独计。沿冻结场景与指令配置预先登记畅通机会窗，未到达或无进展计失效。实际轨迹上的短程扫掠指标用于辅助诊断。零令的速度、停止时间、漂移分别计，危险解除后的恢复以当前命令为目标。
- 完整 R6 全套回归及候选与冻结对照的工程门槛。保留原件、最差轨迹、每类有效事件数和实际首飞时长。调整后的候选使用新的留出组合。

本文件记录待完善的正式协议结构。已完成的连续回放均属于开发评价。正式启动前还需给出精确组合、净空和行为阈值，核验实际 1,800 s episode 所需资源与数据率。

拟在每条首飞预先登记推进、可安全停留和受威胁三类时段，并分别计数。推进段以计划指令为分母，首飞中断后的计划拍保留在分母。安全松杆时段提前要求至少 2.0 s 连续零令，先计算达到和维持低速的时间，再计算距松杆位置的最大位移。受威胁时段记录实际接近、传感可见、保护层介入、危险解除及恢复五个时点。危险尚未解除的零令位移保留为避让诊断。危险解除后再次投影到当拍有效的指令，指令已改向时从新的方向计时。

110 s 首臂每拍约 0.20 s 墙钟。单候选 32 lane 的 1800 s 预计监督墙钟 67–99 分钟、原策略拍记录约 1.2 GiB、串行 CPU 复算约 5–6 GiB。计划单次 7,200 s 工作负载上限及 2 GiB payload，系统盘保留 30 GiB。移动体后续长跑使用整数物理拍计时，以避免 float32 逐步累积带来的约 1.6 s 末端相位偏移。生成器已做独立 32 组的 1800 s CPU 格式与时钟核验。

物理净空原件按 5 ms 保存机体根节点坐标、移动体坐标和机体当拍包络半径。包络按实测刚体链接原点到根节点的距离加各链接碰撞形状半径，取其最大值。复算校验策略拍端点、冻结的几何和包络输入，并从对应表面距离扣除机体包络。相邻策略拍共享端点，首飞的 1,800 s 共有 360,001 个采样时刻。二进制原件每 lane 每物理采样记录 7 个小端 float32，另需约 0.32 GiB。36 s PhysX 配对已验证采集前后两臂的策略拍原始轨迹逐字节一致。110 s 提前撤离对照零接触，但最小策略拍包络净空估计 −0.041 m，室内通过率和零令漂移仍未解决，正式评价尚未启动。 [物理拍核对](clearance/REPORT.md) · [110 秒结果](hover/REPORT.md)

30 分钟契约支持每条街道独立的首次横穿时刻，以及现有 R6 物理入口在 5.0–5.2 秒施加的脉冲。Pulse 方向按 lane 确定，日志逐 5 ms 验证时钟、力和实测质量。启动前逐 lane 核对冻结指令确实包含登记的推进和松杆，支持为不同生成种子登记不同的推进窗口。每类至少三条完整首飞，每条必须通过逐项检查。危险解除后须有连续五拍可执行的非零指令才计为恢复机会。恢复要求连续五拍沿各拍最新指令达到请求速度的 60%。分别留存第一拍与第五拍，正式门槛计到第五拍结束。

拟冻结每条首飞的净空下界 0.15 m、跟踪 RMSE 0.15 m/s、可行移动段至少 60% 的拍达到 60% 请求速度，且连续低进展至多 2.0 s。预登记推进窗口要求实际进展至少达到计划的 60%。在已登记的安全松杆窗口内，1.0 s 内达到并持续不超过 0.07 m/s，最大漂移 0.20 m。危险介入至多 0.5 s，最新指令恢复至多 1.5 s，每条至少 10 个有效危险窗口及 3 个恢复机会。正式输入冻结时同时登记窗口、组合和种子，按完整 R6 回归复核同一份冻结配置。

危险窗口使用真实位置、速度、几何和对应拍的最新指令作独立扫掠复算。间隔不足五拍的预测危险合为一次，避免阈值抖动重复计数。街道的最低覆盖只计实际移动体限制扫掠且有实测移动体回波的窗口，同时保留静态危险和未观测到的移动体风险。每个窗口记录实测位置的净空、移动体限制拍数和见证拍数。

原 30 分钟生成指令的积分在街道达到约 +81 至 +93 m，远过横穿段。正式准备使用 Crazy 生成器的计划位置边界，触界时反射对应的速度分量。积分只读取生成时标和原始速度，保留各 lane 独立种子、五个模式和初始前缀。契约复算每段指令的积分边界。实际危险次数仍由真实首飞轨迹计量，受遮挡、提前终止或未遇到足够危险的轨迹照常保留。
