# 独立复验的两种松杆失效

在轨迹已有撤离且新指令首次为零时，沿用四帧新鲜、角速度和无闭合见证的退出规则。覆盖率低于原 60% 时，额外要求覆盖至少 55% 且最近可靠回波不小于 1.35 m。失败 lane 17 的第 128–130 拍在全窗覆盖 59% 左右、最近回波 1.46 m 以上，无闭合见证。同状态预测停令扫掠最低仍超过 1.15 m。 [失败留出](../independent_second/REPORT.md) · [CPU 原件](CPU-WITNESSES.json)

对已经停稳、当前仍为零令的普通逃逸首拍，保留原同侧、时钟、曲面和两套 0.45 m 表面间距门槛。只在四帧直线拟合的残差介于 0.020 至 0.055 m，且最近两段一致地完成有界折返时，在独立曲面证明中使用原有的折返速度估算。lane 20 第 136 拍原四帧 RMS 约 0.0315 m，最近两段分别复算 0.464 和 0.508 m，合并证明 0.496 m。旧失败见证仍低于第二套 0.45 m 门槛。

同 NOVEL-17 的权重、32 路仿真、120 秒时钟、初态、横穿与脉冲运行单个候选臂，累计 38,400 个评价步，与已关闭原件匹配比较。净空、当前命令、推进和松杆门槛沿用原方案。随后按预登记的全新几何和指令复验。
