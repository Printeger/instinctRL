# 来物同侧净空足够时保持松杆停驻

同一冻结配置在独立 NOVEL-32 五类都守住 0.15 米物理净空，街道两处松杆未通过。lane 22 第 128 拍已有测距支持同侧停驻，停后方向的曲面余量 1.084 米，原提前撤离仍持有下发，导致漂移 0.796 米。按原始运动离线复算，立即制动漂移 0.100 米，移动物净空约 0.990 米。lane 20 第 148 拍已停稳，真实来物最近回波 0.845 米，挡住了原偏置停驻的 0.85 米测距条件。最近的未关联有效回波是 1.849 米，离线制动净空约 0.354 米。 [独立失败记录](../independent_along/REPORT.md)

仅当最新指令真零、原控制将启动或维持撤离时，用四帧有时效和角速率约束的曲面重新核对来物。仍有在途动作时，停后同侧曲面余量至少 0.65 米。四帧已经近零且面临普通撤离首拍时保留原 0.45 米和独立曲面复核。原 0.85 米检查继续用于未被可靠拟合的来物首交点解释的其他回波，同时保留原紧急距离和原 governor、ICS。通过才清除旧撤离速率、计时并下发零，继续逐帧审核。

用 NOVEL-32 原场景、原 32 路 Crazy 指令和扰动做同输入修复，配对复核两处松杆及后来街道最差净空约 0.164 米的窗口。五类首飞、最小净空、过门过角和全部松杆通过后，使用已另行登记的第七组独立输入。 [新独立组](../independent_verified_hover/PLAN.md) [原验收门槛](../long/GATES.json)
