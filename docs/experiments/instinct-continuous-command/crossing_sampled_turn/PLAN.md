# 来物在两帧之间折返的停驻对照

复用独立 Crazy 回放的权重 `u2816`、几何、32 路指令和横穿时钟。街道轨迹 17 在第 140 拍起的普通避让使命令零时偏离停驻位置，预设窗口漂移 0.23753 米。 [失败回执](../independent_observed_heading/REPORT.md)

候选仅在普通避让起点且四帧持续零令、旧下发近零时新增一项核对。四帧须支持同一球面，首末两段运动须反向且共线，中间段接近静止并留在同一条线。用标定后的球心、球半径和旧指令残留重算两段最小横向间距，且须独立核对其他近距回波。下一拍沿用已有证明和拦截裁决。 [CPU 证据](CPU-WITNESSES.json)

CPU 闭环在记录姿态和固定姿态下都把预设窗漂移降到 0.001 米以内。第 156 拍出现新的非零指令时，原保护立即避让。原街道接触、既有折返零令及非零触发病例也纳入 CPU 对照。原生仿真检查目标窗、真实最坏净空、所有预设松杆和场景覆盖。 [正式门槛](../long/GATES.json)
