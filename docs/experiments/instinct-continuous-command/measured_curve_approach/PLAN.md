# 来物接近确认的原生配对

`v55` 的首拍限速消除了第 20 路原有接触。第 22 路在同一分支首次续发后改变轨迹，随后接触重置。两处触发前的匹配球心测距给出相反证据。第 20 路最近两段缩短约 9.3 和 11.7 毫米，第 22 路增加约 13.3 和 10.9 毫米。 [原生配对回执](../measured_curve_slew/REPORT.md)

`v56` 要求同一来物最近两段球心距离各实际缩短至少 3 毫米，才允许原有提前选向。沿用四帧测距关联、首拍 0.30 米每秒增量、0.39 米预测余量、0.40 弧度每秒角速限制及原控制优先级。测量用当前关联的实收球心，每帧距离对坐标旋转不变。未取得连续接近证据时由原路径继续处理。

冻结核对第 20 路接近及第 22 路远离的生产控制动作，另查第 18、23 路和一条二次折返反事实。原生复放 N108/N110 完全相同的 32 条仿真 Crazy Command Generator 序列，每条 120 秒，共 38,400 个评价步，零训练。检查第 20 路净空、第 22 路轨迹和净空、其余路线首飞、松杆、原行为审核及可行低进展。该配对继续使用 B `u2816`，正式 R6 和独立 30 分钟均按原阈值另行验收。 [正式阈值](../long/GATES.json)
