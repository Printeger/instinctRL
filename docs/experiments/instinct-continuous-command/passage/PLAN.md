# 零令时保持原位的同权重对照

复用 HOVER-01 的 110 s Crazy Command Generator 序列与五布局往返来物、B 权重、控制种子和提前撤离配置。候选只在零令的新逃逸首拍检查四帧 LiDAR、IMU 角速度和过去下发指令。以局部相对回波估计最近擦身距离。过去下发速度不超过 0.08 m/s、跟踪拟合和时序可信、估计最近距离至少 0.85 m 时，让本拍保持零令并于下一拍重新检查。没有改动后续急停或有杆提前撤离。仅使用可用测量，不读场景或移动体真值。

CPU 影子先用 HOVER-01 的 53 个实际零令逃逸首拍验证区分信号。筛出 25 个有稳定历史且清楚擦身的首拍，估计最近距离均超过 0.85 m，事后用球体物理路径复算的原位保守净空均超过 0.55 m。被拒绝方案 lane 18 第 813 拍的接近只有 0.078 m 原位包络余量，局部回波估计 0.353 m，会继续走既有逃逸。CPU 影子沿冻结状态复算，实际闭环需重新评价完整 110 s。

两臂都记录 5 ms 净空和全部策略轨迹。逐类核对接触、提前终止、过角、零令漂移与持续推进，在相同指令窗口比较当前命令恢复。关注此前出现的第 282、385、846 拍，以及提前撤离对照末端的窄净空。两臂共有 70,400 个 PhysX 评价步，单次初始化，工作负载上限 1,800 s，结果上限 512 MiB，系统盘保留 30 GiB。这一轮用于开发。
