# 横穿撤离的短时制动复核

NOVEL-31 沿向动作已实际连续下发六拍，第 1,074 拍却在仍需避让时切回横移。同状态复算，持续下发的来物预测间距为旧动作 0.451 m、沿向 0.690 m。把动作保持 0.6 秒后制动，并在原物理预览的 2.4 秒内测算，结果为旧动作 0.321 m、沿向 0.441 m。物理包络投影分别为 0.078 m、0.199 m。

只有同一零令、停驻预测仍见威胁、先前沿向已有实测复核且当前重新测算仍满足原来物和回波门槛时，才用短时预览判断是否续用。原动作短时低于 0.36 m、沿向达到 0.36 m 才允许该分支续用。综合预测间距达 0.45 m 且短时预览通过，才使用原四拍有界续持。每拍原 governor 和 ICS 继续决定是否下发，紧急限位继续有效。

0.6 秒后永久停住仍可能在后段接触。此项复验要实际核对绕让是否持续到危险解除，以及用户新指令能否恢复。使用与 NOVEL-31 完全相同的场景、32 路 Crazy 指令、扰动和 B 权重。 [回放和 CPU 复算](CPU-WITNESSES.json)
