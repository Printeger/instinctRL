# 横穿前置选向的首拍增量配对

沿用 N108 和 N109 的场景、权重、Crazy 指令、启动脉冲和停车窗。N109 原生复盘显示第 20 路首拍选向已生效，但次拍角速 0.486 弧度每秒超过分支的 0.40 弧度每秒条件。第 18 路另有三拍与原截线选择竞争，冻结审核拒绝原始结果。 [配对失败原件](../measured_curve_deflection/REPORT.md)

新配对把第一拍从已下发速度到新速度的变化限制在 0.30 米每秒，按实际首拍速度差扣减预测路径余量，仍要求起始余量至少 0.39 米并通过完整 ICS。后续仍核对新鲜历史和原 0.40 弧度每秒条件。已有截线、制动、已验证交回和绕行拥有优先级。逐路验收保留 0.15 米物理净空及原有松杆、跟踪和恢复阈值。

CPU 姿态响应以 N109 单拍动作和 N108 原轨迹的差估计，首两拍预测角速为 0.335 和 0.324 弧度每秒。该模型仅适用于该局部对照。冻结前重新核查三档速度响应以及有无二次弯曲。原生运行核对第 20 路是否保留足够多拍动作、是否消除接触、其他场景是否退化以及行为审核能否闭合。
