# 保留仍可下发的既有撤离

对照为配对确认的短时连续撤离版本。候选只处理两个保护动作相互指向不同侧时的交接。如果既有撤离经当前 ICS 仍下发至少 0.12 m/s，拟合缺失时的延续须与其方向一致。当前可靠预测预计仍会发生机体包络接触时，保留新选向；预计表面间距仍至少 0.21 m 时，新鲜拟合也优先保留同侧撤离。如果旧动作已裁零，保持新鲜拟合及同样的候选动作空间。

原 lane 21 第 977 拍开始向 −X 撤离，第 982 拍新预测单拍选 +X。延续使 +X 在第 983–986 拍持续。第 987 拍实际 X 速度从对照 −0.185 m/s 变为候选 +0.116 m/s，候选在第 1009 拍接触。原旧版无接触，最低包络净空仍为 −0.025 m。测距复算第 982 拍旧动作表面间距约 0.328 m，可完全下发。第 983–986 拍的旧方向同样通过 ICS。反例是 lane 23 第 116 拍，带撤离标志的旧方向裁零，对侧动作可下发。lane 22 原有第 911–915 拍成功避险无旧撤离标志，继续作为接触回归。

使用同 B 权重、32 路冻结 Crazy 指令、初态、横穿相位和扰动，每臂 120 秒，76,800 个评价步，1,800 秒工作负载上限，512 MiB payload，保留系统盘 30 GiB。报告本次目标及其他所有场景最早接触、5 ms 净空、完成、推进和松杆。
