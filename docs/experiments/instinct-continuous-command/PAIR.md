# 连续指令三臂开发评价

用户授权在项目资源边界内进行本地仿真、GPU 评价及证据支持的训练。首个作业只评价。控制权重和执行版本取自 [B/C 结项](../instinct-post-u1792-two-long/REPORT.md)。二者都使用 25° LiDAR 与 `m4-escape-rear-clearance-p25-v1`。既有 32 lane 物理场景包含门洞、树林、街道和开放管道，每类 8 lane。初始场景、重置种子、指令及控制设置在每个三臂内不变。

[开发指令](PAIR-STREAM.json) 由脚本定义，世界系水平速度上限 0.30 m/s，按 100 ms 消费最新样本。18 s 内保留飞行状态和历史，依次包含起步、变速、反向、斜向、横移、零令停留和再起步。仅街道 lane 有横穿。两条实物横穿轨迹同起点、同方向、同速度、同终点，从两侧各四 lane 横穿，中心线名义通过时刻为 6.4 s（换向）和 4.4 s（错开）。另有同布局、移动体停放于测区外的对照。冻结种子为 167149835。同一份脚本在其他三类只检查连续接线和闭环基本响应，未要求穿过每处门洞或转角。

每拍保留输入时间和事件序号、actor 实收命令及其四帧状态历史、IMU 派生字段、可见回波见证、动作与选中动作、governor、ICS、实际下发和机体响应。PhysX mover 回读、机体状态、任务射线最小值与接触仅用于评价。轨迹记录使用每拍 20 次接触采样的既有接触门槛。被重置 lane 的行为统计在首次终止时截断。球表面到机体根的距离与任务射线最小值分别保留，两者都不能单独当作完整机体包络净空。

诊断用固定横穿参考中心左右各 0.58 m 定义暴露，按实测球位置判定。沿最新非零指令方向测量实际速度与下发，报告解除后首次连续 5 拍达到指令速度 60% 的时间。零令分别给出连续 5 拍 3D 速度不超过 0.07 m/s 的首时刻及最大漂移。若新指令提前切换或首次飞行提前终止，记录实际观察窗。上述是开发诊断阈值。独立真人录制、真人在环、逐类长时留出及正式门槛需在首次正式评价前另行冻结。

单次墙钟上限 1,200 s，原件 payload 上限 512 MiB。由直接入口检查资源、停止信号及关闭对象。至多预留两次同规模发车以覆盖一次故障复跑，分别保留输入和原件。输出使用系统分区普通目录，保留 30 GiB 余量。训练预算不在本文件中授权。

从冻结输入对应的 detached 工作树运行，`INPUTS` 为本轮提交的绝对路径。

```bash
/usr/bin/python3 -B -P -m tools.r6_direct.run --inputs "$INPUTS"
```
