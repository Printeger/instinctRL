# 局部墙面与有限制动的 Crazy 同输入比较

同一 B `u2816` 权重、N67 场景和 Crazy 指令，检查室内与走廊被静态墙面限幅的可行段。候选在原保护未介入时检查当前请求及一组小角度候选。使用最近三帧可靠测距验证候选方向两侧的前向覆盖，并把排队指令、历史余速和随后制动计入 0.60 秒占据范围。若只有局部墙面的约束阻挡，须在三帧都确认该回波位于占据范围外才解除。其余限制、原紧急制动、横穿保护与零令逻辑保留。 [同输入对照](../crossing_restart/REPORT.md)

固定原室内轨迹 1 第 455–496 拍和走廊轨迹 25 第 736–811 拍，按原拍号比对实际推进、跟踪误差、物理净空以及新位置上可行拍的变化。逐拍核对候选目标、原限幅结果、实际下发、解除的限制束及制动占据余量。五类首飞、停车窗、室内路线和危险恢复门槛与既定计划一致。 [正式门槛](../long/GATES.json)
