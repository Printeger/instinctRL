# 按测距时刻补偿机体运动的同权重配对

对照为 NOVEL-03 的预测撤离配置。本轮只改来物运动拟合前的位移补偿。旧配置用当前下发历史估算的瞬时响应补偿跨四帧拟合。候选先按每拍历史下发和陀螺仪旋转维护短时响应，在各帧实际交付时刻近似补偿机体位移，再拟合来物运动。保留现有候选动作、预测时长、净空门槛、保护层与零令释放。执行层补偿使用已下发指令和 IMU，策略输入格式与冻结 B 权重延续。

原预测撤离配置消除了先前两次晚段街道接触，又在 lane 21 第 92 拍出现接触。初次轨迹差异位于第 65 拍，原下发约 −0.217 m/s，撤离变成 +0.296 m/s。固定输入复算表明，按观测时刻补偿后第 65–66 拍保留回撤，第 67–68 拍同向加大回撤，随后恢复原退向。原 lane 22 第 677 拍和 lane 18 第 1108 拍仍选择 −X 撤离。以闭环实际方向、原三处风险窗口 5 ms 净空、全程接触与重置、其他布局行为检验上述预测。 [CPU 证据](CPU-WITNESSES.json)

使用同一 32 路模拟生成指令、相位、物理扰动与初态。两臂各 120 秒，共 76,800 个评价转换，仿真初始化一次，1,800 秒工作负载上限、512 MiB 结果上限、系统盘保留 30 GiB。训练和模型写入均为零。本轮属于开发配对。
