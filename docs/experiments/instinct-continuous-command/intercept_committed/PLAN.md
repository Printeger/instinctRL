# 在短暂拟合空档继续已验证的撤离

对照保持停留余量版本。候选只在已经选中有效横向撤离、下一拍曲面预测暂时无法使用的情形下，保留已确认的方向最多四拍。每拍用陀螺仪旋转原方向，并由原 ICS 重新计算最少 0.12 m/s 的可下发速度。紧急停止、有效最新测距缺失或当前新测距可重新拟合时结束这次保留。下一拍使用新拟合重新判断。原预测、权重和停止余量保持相同。

NOVEL-06 的新增接触发生在 lane 22 第 942 拍。第 911、916、921、926 拍都选中可下发的 −X 撤离，下一拍经历四帧角速度门槛拒绝，旧动作重新下发 +X。使用当拍真实测距对固定方向重放，这四处各随后四拍的 16 次 ICS 均允许撤离。验证连续选向、撤离是否仍可下发、该窗口逐 5 ms 净空和五布局全程新增接触。原停留余量的早段收益及其余横穿也一并复核。 [CPU 核验](CPU-WITNESSES.json)

两臂复用同一 B 权重、32 路模拟 Crazy 指令、横穿相位、初态和扰动，各 120 秒，共 76,800 个实际评价步。单次初始化，1,800 秒工作负载上限，结果上限 512 MiB，系统盘保留 30 GiB。
