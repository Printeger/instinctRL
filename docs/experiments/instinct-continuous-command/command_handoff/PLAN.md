# 当前方向可行时结束旧逃逸

候选继承上一轮的 B 权重和保护执行。新增条件只检查普通逃逸持有途中，非零指令是否大幅改向，且新方向已经离开原触发威胁。只有扫描时钟和范围正常、当前新方向有足够可靠测距、新方向通过原 ICS，且原 actor 沿新指令的实际可下发速度有明显收益时，才结束旧逃逸。选择原 actor 动作并清除旧选项屏蔽，经历相同 governor、ICS 和移动预测保护。之后新威胁仍可触发。

归档 NOVEL-03 的 55 个符合角度窗的中途改向中，同状态实算有 14 个可以交接。室内 lane 0、1、7 在第 200 拍从向前改为正横移，但原保护仍下发约 −0.30 m/s 横移。屋内离威胁原方向的夹角约 90°，原 actor 的 +0.23 m/s 横移三条都可下发。14 个候选在固定尾迹的 2.4 s 离线几何投影中，最小净空约 0.374 m。原曾发生接触的街道 lane 18 第 642 拍是另一个可交接实例，较晚同方向被裁零的反例保留。 [同状态 CPU 复算](CPU-WITNESSES.json) · [原始街道复验](../novel/REPORT.md) · [转角基线](../corner/REPORT.md)
