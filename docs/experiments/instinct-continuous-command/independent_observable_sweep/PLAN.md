# 新种子的独立街道回放

使用通过限定垂向补偿配对的单一执行配置与 B `u2816`。五类原样，32 条各自的 Crazy 指令和新场景种子均在原生评价前冻结。球仍为半径 0.34 米的物理碰撞体，沿原 XY 范围进行独立两轴往返，球心高度 2.24 米，X/Y 峰值 0.30/0.46 米每秒，端点加减速各 1 秒。相位只来自场景种子、路号与固定初始区域，不随实际机体或 Crazy 指令调整。

两组从未原生飞过的种子用于事前几何判别。64 个 30 分钟模型格中，每格存在 16–39 个严格动态危险窗。严格口径要求固定球时净空通过，真实移动使净空至少再减少 0.04 米且跌破 0.15 米。每格至少十个同时有及时四帧回波和模型可行避让。把同一条历史第 23 路仅改球高，四帧回波提前十拍，历史轨迹仍跌至 0.070 米。CPU 判别中仍有迟回波，所有原始双轴折返失败继续保留。 [既有折返结果](../observed_turn_braking/REPORT.md)

原生开发评价使用新场景与新 Crazy 种子，32 路各 120 秒，38,400 个评价步，一次显式初始化，零训练。墙钟 1,200 秒，载荷 512 MiB。逐路核对首飞、最小净空、预设停杆、实际跟踪与恢复，并复算真实动态危险覆盖。完整 R6 由这份相同冻结源码和已通过短程护栏的独立回放发车。 [原门槛](../long/GATES.json)
