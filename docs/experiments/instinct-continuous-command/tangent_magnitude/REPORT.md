# 墙面切向速度配对结果

候选与有限边缘对照各完成 32 条 120 秒首飞，共 76,800 个实际评价步。各臂零接触、零自动重置、零提前终止，32 个预设松杆窗口全部达标，室内门洞与转角均为 8/8。两臂全组最低净空均为 0.225 m，出现在街道 lane 23 的 32.435 秒。树林的 5 ms 最低净空由 0.485 m 变为 0.434 m。 [逐场景及原件](RESULT.json)

走廊 lane 26 和 27 第 91–144 拍，对照实速均为 0/54 拍达到沿原指令 60% 的门槛，候选均为 54/54。两条的同期轴向推进各约从 0.84 m 增至 1.31 和 1.30 m，lane 24 与 25 的同期轴向推进却下降约 0.25 和 0.34 m。按正式可行推进定义复算，走廊最长连续慢速从 5.7 s 降至 4.5 s，树林升至 8.5 s。后续 IMU 对齐配对仍以有限边缘控制为起点。 [正式指标的开发复算索引](../rotation_tube/CPU-WITNESSES.json) · [IMU 对齐试验](../rotation_tube/PLAN.md)
