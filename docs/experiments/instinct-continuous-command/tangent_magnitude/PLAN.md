# 按最新请求模长复核已确认的墙面切向

NOVEL-16 走廊两条轨迹有 54 拍请求 `(0.15, 0.19) m/s`，保护层下发 `(0.15, 0) m/s`。原方向的投影约占请求速度的 38.4%。同状态复算中，四条走廊抽样的 36 拍使用同一已确认切向、速度等于最新请求模长，均通过原 ICS，投影为 61.96%，固定姿态轨迹的最小推进再停估计净空为 0.620 m。另复查冻结原 R6 三个迎墙块的 1,236 个已裁切拍，均未得到切向确认。 [前轮结果](../finite_edge/REPORT.md) · [CPU 计算索引](CPU-WITNESSES.json)

恢复到 NOVEL-16 的有限边缘控制。只有原切向通过现有保护且推进未达到六成时，才尝试同方向、限在最新请求模长内的动作。尝试动作仍须通过原 governor、ICS 和移动体保护，并提供六成推进。保持迎墙制动、动作时钟和输入边界。短时延续的试验发现部分进展退化，单独归档。 [延续试验](../edge_continuation/PLAN.md)

候选与原有限边缘控制按同一 B 权重和 32 路指令各执行 120 s，共 76,800 个评价步。分别记录被抽样的切向进展、整体跟踪误差、预设松杆、连续可行低速、逐拍净空以及接触重置。正式门槛按既有计划执行，经闭环选定的配置再进入预登记的独立留出与完整 R6。 [独立留出](../independent_second/PLAN.md)
