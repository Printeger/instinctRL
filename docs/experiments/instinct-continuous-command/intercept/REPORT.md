# 预测撤离消除两次晚段接触并新增一次早段接触

同一 B 权重、同一 32 路 Crazy 指令、各 120 s。预测撤离候选将两处晚段接触窗口的 5 ms 净空下界从 −0.049 m 和 −0.084 m 提到 +0.634 m 和 +0.529 m。候选在街道 lane 21 第 92 拍新增一次接触，最低 −0.063 m，候选首飞 31/32。对照 30/32，较早结束的候选使街道首飞累计从 904.6 s 减至 849.3 s。其余四类均完成并保持相同最差净空。 [逐类、窗口及实际下发](RESULT.json)

新增接触前，第 65 拍的原指令已换到 −X。对照继续撤离，候选改为 +X 并把机体带回横穿路径。运动拟合取的是过去三段测距，响应补偿却用了偏向最新下发的值。换向期间这会把机体速度变化误算为来物横向运动。下一轮按各测距时刻补偿机体位移，核对初始两拍和随后的转向。 [同权重配对](../intercept_aligned/PLAN.md) · [原尾迹 CPU 复算](../intercept_aligned/CPU-WITNESSES.json)

早重置改变了 lane 21 在计划横穿中心时刻的来物位置，初版读回因此失败。修订后在重置前最后一个物理边界比对期望位置，接触和重置仍保留。复核通过时序、输入、发动机下发和两臂各 40 个扰动物理拍。原生退出仍为清理超时和 −15，所属进程均退出。 [回放绑定](RESULT.json)
