# 横穿预计相交时的同权重撤离配对

复用 NOVEL-02 的 32 路 Crazy 指令、场景、B 权重、扰动和全部时钟。对照使用零令折返版本。候选在既有保护层最终选择后，用四帧测距识别形状稳定、确有接近的曲面回波。按测得的相对运动和历史下发的短时响应模型，预测未来 3 秒的平面间隔。若原动作预计表面间距小于 0.36 m，则计算保持以及相对运动轴两侧的可下发动作。保持须达到 0.42 m 且改善 0.12 m。侧移须达到 0.28 m 且改善 0.15 m。原 ICS 核验每个动作，保留原全方向紧急停止。新计算只读取既有测距、IMU、扫描时间和执行历史。

NOVEL-02 首飞接触分别出现在街道 lane 22 第 706 拍及 lane 18 第 1138 拍。两条在到达最近距离前已经停止下发。冻结原尾迹复算在 lane 22 第 677 拍最早检出此次相交。在 lane 18 第 1108 拍已有四帧形状拟合，但当前响应模型给出的前两个侧移候选仍朝 +X，第 1110 拍转向 −X。报告实际选择、相邻拍是否抖动、5 ms 净空、原接触窗口及整条首飞新接触和推进。保留原回放的两个起始接触窗口，并按其他四类和所有街道 lane 核对新增变化。

两臂各 120 秒，评价共 76,800 个转换。单次仿真初始化，1,800 秒工作负载上限，512 MiB payload，系统盘保留 30 GiB。用于开发匹配。训练和模型写入均为零。
