# 在可靠回波允许下发时提前撤离

两条往返回程接触在晚撤离中未解决。冻结 CPU 影子回放验证了 lane 17、23 在第 254 拍已有可靠斜向收近，原 ICS 允许约 −0.30 m/s 的反向速度。到第 268 拍，原轨迹两条反向候选均被裁零。晚撤离只在第 265、267 拍开始，实际反向来不及建立。 [晚撤离结果](../return/REPORT.md)

固定 B、v2 执行对照、场景、种子、指令和移动体原件，跑相同 36 s 连续前缀。候选在非零人令、既有逃逸未接管、传感器新鲜且可观测的斜向收近时，提前尝试反向撤离。原 governor/ICS 判定能下发后才接管，至多保持 1.5 s，再交回当前指令。无法下发时走原路径。晚撤离的候选分支不启用。

两条已知接触都消失才算解决本轮失效。所有场景不得新增接触、提前终止、重置。固定走廊等畅通段的跟踪和推进分母，在同一指令和轨迹时窗复算；其余仍以现有开发指标检查。更晚发生的零令逃逸接触保留为单独失效。 [固定跟踪机会](OPPORTUNITIES.json)

单次模拟器初始化，两臂共 23,040 个评价步，墙钟上限 1,200 s，payload 512 MiB，系统分区保留 30 GiB。无训练。
