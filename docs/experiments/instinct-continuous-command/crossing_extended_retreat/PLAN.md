# 同侧撤离时长的同输入复验

固定上一组的 B `u2816`、几何、Crazy 指令、横穿时钟与五类 32 条首飞。上一组街道 lane 17 第 1067 拍的同侧候选通过 ICS，按 1.5 秒下发后刹停的保守净空只有 0.3445 米，随后发生实际接触。 [上一组原件](../crossing_stop_receding_hover/REPORT.md)

同侧动作的旧持续时长保留。只在原撤离确定会穿过来物运动线、且同侧动作需要更长时间才能满足 0.39 米内部预测门槛时，以 1.8 秒重新做扫掠、静态净空、带残留指令的停止包络和来物速度扰动复核，通过后安排 18 拍。由当拍传感器和 ICS 标准限制后续动作。第 1067 拍的 CPU 保守预测为 0.4332 米，独立物理近似为 0.2850 米。 [CPU 证据](CPU-WITNESSES.json)

同输入复验沿用物理最低净空 0.15 米、首飞零接触及中途重置、室内过门过角各 8/8、32 个松杆各 1.0 秒和 0.20 米内。通过后使用原先登记的第八份独立输入。 [独立输入](../independent_receding_hover/PLAN.md)
