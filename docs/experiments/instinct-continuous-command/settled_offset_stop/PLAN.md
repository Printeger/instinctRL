# 已停稳时确认移动体安全擦肩

街道 lane 21 和 23 在第 144、150 拍重新触发逃逸。触发的 12、16 条支持束均击中移动体。四帧响应补偿后的侧向表面间距估计为 0.520、0.599 m，尚低于旧 0.65 m 门槛。另一套现有的严格曲面停车判据独立确认安全擦肩。把真实机体固定在触发时位置，用随后四秒的 5 ms 来物原件离线复算，包络净空下界为 0.309、0.394 m。该复算用于筛选候选，实际接续轨迹由物理回放测量。 [原配对](../offset_stop/REPORT.md) · [正式启动前固定 CPU 原件](CPU-WITNESSES.json)

候选只在普通逃逸首拍使用较短停车条件。四帧原指令均为零、先前实际下发速度至多 0.08 m/s、时钟新鲜、最近可靠回波至少 0.85 m 时，补偿后的全路径侧向净空和另一套严格曲面停车判据同时至少达到 0.45 m，保持零下发。第 1119 拍的 lane 22 侧向估计为 0.463 m，第二套判据未确认，维持原逃逸。第 195 拍的 lane 17 最近可靠回波为 0.849 m，同样保留原逃逸。整体反向退避和 ICS 紧急制动继续执行。

使用同一 B 权重、32 路 Crazy 指令、相同初态、横穿和物理扰动。对照为已完成相邻历史物理配对的执行方案，继续使用原正向停止距离。两臂各飞 120 秒，评价上限 76,800 个转换，墙钟 1,800 秒，输出上限 512 MiB，系统盘保留 30 GiB。对比两个松杆窗、其后首飞接触和 5 ms 最小包络净空、静态通行及已通过的回逃窗。
