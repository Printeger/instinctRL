# 零令低速避让的姿态复核

在 CPU 上复用冻结 v60 的下发和 B u2816，复放 NOVEL-115 街道第 19、22 路的停杆窗与之后的交会。先跑 0.35 秒响应和原件姿态下的配对。对照是既有 0.065 米/秒低速避让，候选仅在普通新鲜度检查失败时，尝试用独立实测静态面重新证明旋转对齐。仍要求原来的时钟、扫描支持、加速度上限、原 ICS、0.39 米短证和转零后备。对齐后的来物拟合另加基于角误差的范围余量。

两路按原 0.07 米/秒停稳、1.0 秒和 0.20 米漂移线重新评分。跟到第 242 拍，核对 5 ms 最低净空和恢复当前指令，保留 0.15 米与 1.5 秒要求。固定姿态是诊断对照。只有录存姿态下的同输入通过才扩大到 0.25、0.45 秒响应与同历史变体。此配对使用录存姿态作为外生输入，并用因果速度响应模型重绘扫描和下发，属于反事实诊断。

## 相对墙面的旋转旁证

第一轮录存姿态复算中，第 22 路用于配准的两个墙面接近平行。追加一组同输入 CPU 对照，检验这两个相对墙面能否约束重力已确定后的偏航。两面俱须覆盖原有采样、延续和残差门槛，夹角距反向不超过 0.02 弧度，四帧估计墙间距的变化不超过 0.004 米。复用角速、角差门槛及额外范围余量，沿通道平移仍由原命令响应估计。沿用上面的通过条件。
