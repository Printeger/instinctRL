# 相对墙面复核救回停杆，换令恢复仍慢

冻结 v60 和 B u2816 的记录只用于 CPU 反事实复放。第 19、22 路均从相同原件初态、录存姿态和既有 0.35 秒速度响应开始。复放从到达各自停杆关键拍开始，随后运行到第 242 拍，净空按 5 ms 评分。停止与恢复沿用原登记时钟。

已有的多方向平面复核对两路都给出与严格新鲜度相同的下发。第 22 路第 173 拍角速达 0.477 弧度/秒，触发额外复核。两个墙面各有至少 1,122 个支持点，角差仅 0.000498 弧度，水平法向最小奇异值约 0.000007，未通过独立法向要求。相对墙面方案只复核偏航，检查两侧墙面角差和墙间距是否稳定，沿通道平移仍使用原命令响应模型。第 173–183 拍共获得 11 个允许继续拟合的复核见证。

第 22 路的新指令第 198 拍生效，恢复共钟起点为第 201 拍。复核后的原撤离逻辑在此后仍以约 0.45 米/秒向反方向撤离，到第 215 拍才实际下发新方向，连续五拍的实测确认在第 228 拍。恢复仍超过 1.5 秒。该段原策略直下发在第 212 拍及以前的 ICS 系数为零。当前证据支持保住零令停稳的局部机制，也暴露了撤离减速和交回当前指令的独立缺口。
