# 录存姿态下的撤离交回对照

保留相对墙面复核和 0.065 米/秒停杆路径。只在同输入已自然结束的停杆局部续放，使用冻结 v60、B u2816、NOVEL-115 初态、来物和录存姿态。主对照是前次两面复核原件。新对照使用既有 0.30 米/秒首拍变化上限和原 ICS，在已有 0.39 米保持与转零证明内选择对最新非零指令沿向最大的一步。比较换令后才做选择，以及结合既有零令尾段、具备三档响应证明时提早降低撤离速度。

首先仅评价第 22 路、0.35 秒响应。沿用第 201 拍共同起算点，连续五拍实测沿向达到最新指令的 60% 才确认，要求 1.5 秒内、停杆 1.0 秒内、漂移不超过 0.20 米、最低净空至少 0.15 米。同时记录第一次正向下发和足量下发，避免用更晚的可行窗口掩盖恢复迟缓。只有本局部配对达标才扩大响应档位和对照。全部结果只属于 CPU 反事实。

另用第 203 拍的同前缀实收数据筛查两段动作。第一拍须过原 ICS、单拍变化上限，并至少达到计算出的按时恢复必要沿向速度。第二拍枚举同一个速度方向网格，仍限单拍变化。只计算独立来物加速度界和三档响应下的 0.60 秒动态下界，暂按第二拍可下发。若有候选，仍须补静态和下拍实际执行证明。若无候选，结论仅覆盖该拍与登记的动作网格。
