# 松杆后撤离的早期选向

使用冻结的 v60、B u2816、NOVEL-115 第 22 路原输入和录存姿态。从同一低速停杆与相对墙面复核路径出发，保留通过原来物重建和已冻结沿向桥接的状态。首先在 0.35 秒响应档，比较已关闭的西向撤离与两个候选。只有原逻辑从低速停杆转入撤离的那一拍才允许选新方向，撤离前的停稳处理依旧。备选在实测重力平面枚举 72 个方位。首拍须过原 ICS，0.60 秒保持与 0.20 秒转零后备都须有 0.39 米，首拍变化不得大于原撤离。

第一候选沿用原最高 0.4499 米/秒，选相对原动作的远端净空估计至少多 0.01 米的方向，在合格集合中最大化估计净空。第二候选限定总速和首拍变化均最多 0.30 米/秒，要求远端净空比转零至少多 0.01 米，在合格集合中最大化估计净空。两个候选都在每个零令拍检查原 0.20 秒保持和转零后备，续证失败时保留原逻辑的动作并记录。非零指令继续由已经冻结的桥接方法接收。来物真值和全局轨迹只用于 CPU 场景重绘和评分。

维持第 201 拍恢复起算点和连续五拍实测 60% 要求，局部净空至少 0.15 米、在 1.0 秒内停稳、漂移不超过 0.20 米、恢复不超过 1.5 秒。只有达到以上同一局部门槛才扩大响应档或同历史变体。结果属于有限窗口 CPU 对照。
