# 撤离交回的候选局部细化

沿用 v60、B u2816、NOVEL-115 第 22 路录存姿态、相对墙面复核、斜向撤离与再次接管时逐拍续证。当前 CPU 对照以 1.6 秒确认，第 211 拍实际沿向缺 0.00930 米/秒。仅在原换令桥接已经运行的拍，根据当前指令、上一拍真实下发和原有限网格的最优合格方向增加局部候选。加入 ±2、±4 度的小邻域、±0.025 米/秒小步，以及保留部分横向的沿令插值。候选仍须过原 ICS、0.30 米/秒下发速度和单拍变化约束、0.39 米保持与短制动后备，沿向上限仍为当前请求速度。细化只在能够改善沿向时替代原动作，原计分时钟与合格标准沿用。
