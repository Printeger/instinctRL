# 横穿时保护层合成命令的原生配对

`LONG-01` 的街道第 22 路在第 769 拍记录实际接触及中途重置。5 ms 原件在 76.340 秒首次低于 0.15 米，在 76.950 秒的动态净空下界为 −0.06758 米。第 720 拍，策略已压低朝来物轨迹的速度，保护层组合出的侧移命令仍朝向该轨迹。按这一实际下发命令预测执行 1.5 秒再刹停，来物净空下界为 0.010 米。 [CPU 证据及原始输入](CPU-WITNESSES.json)

`v41` 在原保护层完成仲裁后，用当拍远距回波检查下发速度是否会切入来物轨迹。仅在原策略速度已受抑制、没有优先级更高的停驻或撤离动作时尝试同侧斜向撤离。每拍以完整 ICS、有限时长净空和指令有效性重新认证。同一指令至多续证五拍，主方向当拍被 ICS 限制时才检查较浅的同侧方向。改令或观测过期即结束续证。该改动不接入仿真真值，保留 B `u2816` 权重。

从相同遥测前缀复算，第 22 路在 0.25、0.35、0.45 秒响应滞后三档、两种姿态处理下的最小模型净空分别为 0.175、0.381、0.344 米。慢响应档原方向有两拍被静态回波限到零，较浅续证通过这两拍。N83 与 N93 的两个街道反例各有 44 和 41 拍，候选和对照的下发与响应逐拍一致。CPU 模型仅覆盖目标片段及反例。 [逐拍模型证据](CPU-WITNESSES.json)

原生配对 `NOVEL-98` 读取 `LONG-01` 的同一 32 路 Crazy 指令文件、场景种子、碰撞包络、横穿起始时刻、脉冲参数及初始重置后的 120 秒。对照使用已记录的 `LONG-01` 原件。候选共 38,400 个评价步、一个显式初始重置、零训练，工作负载上限 1,200 秒，载荷上限 512 MiB。核对原失败窗口内接触、重置与 5 ms 实际净空，并读取其他轨迹、门角、停杆和全组短程行为数据。 [对照输入](../long/R6-DIRECT-INSTINCT-GPU-COMMAND-LONG-01-inputs.json) [冻结门槛](../long/GATES.json)
