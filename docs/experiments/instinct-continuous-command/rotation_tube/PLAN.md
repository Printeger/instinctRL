# 用 IMU 历史对齐室内通道确认

NOVEL-16 室内 lane 5 的低进展窗口有 95 拍，其中 68 拍由 ICS 裁零。第 306、316、340 拍的旧指令持续向前，原射线证据仍显示 0.41 m 轴芯为空，俯仰脉冲却超过原 0.22 rad/s 的三帧门槛。用原 IMU 角速率和实收指令对齐测距轴，实装 CPU 复算额外放行 lane 5 的 11/23 个抽样拍及 lane 7 的 2/20；用固定原轨迹复算推进再停，最低净空分别为 0.230 和 0.217 m。街道 71 个可见横穿物且旧 ICS 裁切的抽样拍均未额外放行。原 R6 三个迎墙块的 1,236 个已裁切拍未进入新增角速率范围。 [CPU 原件和参数](CPU-WITNESSES.json)

仍以有限边缘控制为对照。候选在时钟新鲜、角速率介于 0.22 与 0.38 rad/s 且最新连续请求可在共同坐标系复核时，用三帧各自的修正轴重验空芯和左右远端见证。旧方向的角度残差按距离扩入空芯，原测距稳定性、两段回波历史、速度上限和紧急制动条件继续生效。控制只读取批准的 IMU、测距、时间及命令历史。

两臂各 32 条 120 秒首飞，共 76,800 个评价步。固定权重、几何、Crazy 指令和物理扰动，逐场景比较裁零拍、连续可行低速、松杆、推进及 5 ms 净空。依据配对结果冻结候选，通过预登记新独立输入复验后进入完整 R6。 [有限边缘对照](../finite_edge/REPORT.md) · [独立留出](../independent_second/PLAN.md)
