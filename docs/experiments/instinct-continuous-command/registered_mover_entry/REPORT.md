实际第 372 拍实收扫描中，原首拍目标继续下发仍可取得 0.473 米计划和 0.494 米转零备份余量，完整 ICS 为 β=1。允许按实收数据续发的 CPU 对照在第一个窗口最低 0.219 米。扩到同一路后半段时，使用归档姿态的 CPU 对照为 0.430 米，固定姿态对照降至 −0.090 米。保留两组，下一候选须通过后半段的共同反例。 [复盘原件](POSTMORTEM.json)

若实际初态保留既有一拍队列、速度变化上限为 0.30 米每秒、其后平移上限为 0.45 米每秒，第 717 拍即使允许任意平面后续动作，最差响应的可达净空上界也仅 0.126 米。当前采样的实体净空到第 724 拍才首次跌破 0.15 米。将来物提前 0.2 秒后，可达上界在第 715 拍已降至 0.125 米。后续须验证能更早介入的实收证据。正式验收未通过，未发起同版全量 R6 或新的独立 30 分钟。 [上界与口径](POSTMORTEM.json) · [正式门槛](../long/GATES.json)

第 688 拍两臂的实收扫描支持来物以约 `(−0.300, −0.460)` 米每秒直行，后一次转弯当时尚不可识别。固定 v59 当时的机体轨迹，延续已观测直线的最小净空为 0.391 米，使用后来实际转弯则为 −0.109 米。因此较早选向的依据应为实收不确定性余量和可持续避让，而非预知折返。 [相同历史的来物反事实](POSTMORTEM.json)

以第 688 拍为起点的后半段 CPU 方案，在一档响应的归档与固定姿态、以及延后 0.2 秒的归档姿态对照中，单独得分为 0.0 秒介入、0.5 秒恢复，局部净空 0.235–0.252 米。第 705–708 拍可用两面静态面复核旋转余量。组合前半段续行后，原会触发的排序避让有时变成正在保持零下发的制动，单独的后半段证据不能合并为整路通过。 [冻结评分与状态反例](POSTMORTEM.json)
