# 零令时保留已确认的横穿撤离侧

同输入 NOVEL-34 在街道 lane 22 第 517 拍把振荡接近零误作停令，反向撤离后新增接触。lane 19 第 1,077 拍重新拟合到来物，但原东向及附近所有小角度候选被原 ICS 裁零。常规西向下发会压缩已建立的间隔。 [两处实际结果](../crossing_stop/REPORT.md)

新分支仅在最新指令为真零时选择有限横向动作，并禁止反转已经确认的撤离侧。若当前可下发动作朝来物包络逼近、上一拍仍向已验证侧运动，可评估一个更陡的同侧后斜向。候选仍须通过原 governor 与 ICS。停后到来物线和回波距离保持至少 0.39 米。更陡的续持只在原下发运动预测低于 0.21 米、来物曲面预测提升至少 0.20 米且达到 0.34 米时允许。 这些是开发控制判据，5 毫秒实际物理净空验收仍为 0.15 米。

同状态复算，lane 22 第 517 拍恢复原西斜向。lane 19 第 1,077 拍的后斜向以原 ICS β=1 放行。无延迟收益的两秒运动后刹停，五秒离线物理投影最低约 0.181 米，保持 0.6 秒即永远制动的投影仅 0.001 米，需闭环持续复核。继续使用同一 B 权重、32 路 Crazy 指令和扰动，完整核对两个窗口、逐类首飞、净空与全部预设松杆。 [原验收门槛](../long/GATES.json)
