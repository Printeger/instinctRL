# 保留已确认墙面切向的可执行请求分量

统一降低正向停止距离的候选出现室内通过退化，同状态复算发现原 R6 迎墙保护被削弱。新候选沿用原标量 ICS、0.15 m 余量与紧急制动。仅在普通非零请求被强裁切、最近相关可靠回波落在 0.57–1.05 m 且连续三帧支持局部静态线段时，尝试保留最新请求的水平切向分量。替代方向通过同一 governor、全扫掠 ICS 与来物预测才可下发。正迎墙时切向分量不足，继续执行原保护。 [旧停止距离配对](../confirmed_standoff/REPORT.md)

固定真实扫描复算中，走廊 lane 24 的 25 个抽样裁零拍可保留约 0.15 m/s 轴向运动，模拟 1.2 秒下发后停止的最低包络净空为 0.637 m。树林 lane 8 另有两个抽样拍可继续推进，最小为 0.591 m。已选室内、管道和街道见证保持原动作。冻结前保留正迎墙反例和原始输入。 [CPU 见证](CPU-WITNESSES.json)

复用相同冻结 B 权重、32 路 Crazy 指令、初态、横穿和物理扰动。对照为二次停驻证据通过的配置。两臂各飞 120 秒，共 76,800 个评价转换，墙钟上限 1,800 秒，输出上限 512 MiB，系统盘保留 30 GiB。逐类核对真实推进、松杆、过角、接触和 5 ms 净空。固定同态结果仅作开发对照。
