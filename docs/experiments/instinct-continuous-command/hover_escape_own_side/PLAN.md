# 零令处于横穿旁时的同侧避让

复用已失败独立回放的 B `u2816`、控制输入、世界、32 路 Crazy 命令和横穿时钟。处理街道轨迹 20 第 962 拍的首次向来物轨迹启动，以及第 994 拍的后续实际接触。 [失败原件](../independent_sampled_turn/REPORT.md)

在原保护裁决没有介入时，复查持续零令下刚启动的普通避让。四帧确认来物轨迹，原向横穿的动作扫掠失败，且按旧逻辑停驻余量落在临界范围时，才验证一条本侧斜后向轨迹。候选沿用原 Governor、ICS 和静态回波检查。每拍重新确认净空及方向，确认安全停驻后回到零令，收到非零指令即重新走原裁决。 [CPU 证据](CPU-WITNESSES.json)

用同一批 Crazy 指令比较原接触窗的实际下发、最小物理净空和完整性，同时检查五类全程净空、松杆及路线。走廊有限推进候选待本轮安全对照通过后继续验证。 [走廊候选](../bilateral_stopping/PLAN.md)
