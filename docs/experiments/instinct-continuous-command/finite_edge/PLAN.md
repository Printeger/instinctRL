# 侧绕已观测的有限边缘以恢复推进

独立短程的室内 lane 5 从第 294 拍起有 100 拍连续低进展，95 拍被 ICS 裁为零，无逃逸或紧急动作。按实测初态沿最新指令推进 0.6 s 再停，窗内估计最小净空为 0.445 m。在第 297 拍，用当拍原始测距推得可下发的斜向速度约为沿请求 0.221 m/s、垂直请求 0.121 m/s。初步同状态影子在该窗 32 个抽样拍放行 31 个，固定状态推进后停车的最低预计净空超过 0.49 m。 [独立原件](../independent/RESULT.json)

候选仅在当前普通移动因保护层强裁切时探测约 29° 和 42° 的水平偏向。近缘需三帧可靠且稳定，在其投影深处需看见同侧连续三帧各至少四列可靠远回波。候选动作经过原 governor、完整 ICS 和已有的来物预测，要求沿最新请求至少达到六成并提高至少 0.075 m/s。若原动作恢复可下发，仍执行原选中动作。正迎实墙和缺失回波的否决以 CPU 与已存 R6 样本核对。
