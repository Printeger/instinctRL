# 曲面回波对零令擦身判定的配对

复用同 B 权重、110 s Crazy Command Generator、五布局和物理种子。两臂均使用近险后的回中暂缓和折返逃逸选向。候选只在零令候选首拍增加对四帧局部曲面回波的形状拟合。由传感器测得的曲面中心和半径拟合通过一致性检验时，用中心预测最近距离减去观测半径。估计表面距离至少 0.45 m 才保持原位，其中约 0.21 m 为机体范围、0.15 m 为拟保留净空、0.09 m 为观测裕量。无法可靠拟合时沿用原零令判定。控制根据实收测距、时间、有效性、IMU 角速率和过去下发值估计相关状态。

REARM-01 街道 lane 23 第 1022 拍开始一次零令逃逸。通过当时实收测距复算，原基于表面点中位数的分离估计为 0.822 m，低于原 0.85 m 门槛。曲面估计的最近表面距离为 0.661 m，新代码在同一输入选择保持原位。第 1078 拍附近的回波预测仍显示近险。物理配对检查首拍是否保持原位、后续是否稳定保持净空、绕回过程中后续保护、最新指令推进和其他布局安全。风险沿用 5 ms 原件复算。

两臂共 70,400 个 PhysX 评价步，单次初始化，工作负载上限 1,800 s，结果上限 512 MiB，系统盘保留 30 GiB。只用于开发评价。
