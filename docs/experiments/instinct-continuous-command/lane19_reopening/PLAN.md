# 街道第 19 路的换向后首次恢复下发

复核冻结 v60 的第 1052–1062 拍。原轨迹从第 1052 拍收到约 0.286 米/秒的南向指令，第 1059 拍才恢复非零下发，第 1060 拍进入有限边缘。现有受扰动同权重闭环最早从第 1061 拍撤离，仍有失败。因此先在相同早期观测中检查完整 ICS、1.0 秒两段前视、0.90 秒短发后转零后备和静态余量。候选首拍变化限制 0.30 米/秒，两项净空仍要求 0.39 米。同时披露远端预计净空增量和沿令分量，确认是否存在新可发动作及最早时机。严格入口、受扰动原件和 v60 控制都保持冻结。该复算不推进原生状态，也不以同帧证书作为闭环通过。
