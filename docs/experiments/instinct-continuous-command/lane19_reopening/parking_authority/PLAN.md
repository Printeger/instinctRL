# 第 19 路松杆前的位置转移能力

从冻结 v60 街道第 19 路第 1060 拍出发，采用同一原始队列和实发首拍。保持探索动作 0.4499 米/秒速度上限、正速换向单拍 0.30 米/秒变化上限、0.10 秒队列，并按 0.25、0.35、0.45 秒三个响应时间逐一积分。停令沿用上一轮的直接转零。目标是在同一开环动作序列上同时守住原来物和四种已经登记的横向扰动。

先求第 1070 拍直接转零的可达净空上界。上界允许每个净空采样点及扰动分别选最有利的动作，放开变化、ICS 及静态约束。分别计算水平与三维权限、冻结与自由首拍、持续零与第 1084 拍起任意恢复。若上界低于 0.15 米，该反例可排除此开环停法。若上界超过门槛，还需寻找具体动作。再用先发原首拍、两段水平目标、换向限幅、转零的动作族寻找一条对五种来物和三个响应时间同时成立的序列。第 1070 拍为准时松杆候选，随后每隔两拍检查一次延迟转零直至第 1084 拍。粗筛每 25 毫秒，入围逐 5 毫秒复算原几何静态净空与移动包络。配对持续零与第 1084 拍恢复原 CCG 指令。报告第 1070–1083 拍停留诊断的漂移及松杆 1 秒后的最高速度，并一直计分至第 1110 拍。

本轮使用未来轨迹计分，检验模型中的动作能力。两段动作搜索值只证明所测序列达到的结果。原控制入口、ICS 可发性与正式恢复验收仍需闭环复核。
