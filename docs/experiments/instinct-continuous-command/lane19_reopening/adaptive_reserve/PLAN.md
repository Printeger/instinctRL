# 提前避让的逐拍续行复核

保持第 1052 拍已验证的原始动作，在同一原来物及早分岔正扰动、固定姿态、0.45 秒响应下配对。对照为上轮只发一拍的冻结原件。新臂在每一拍只使用当前四帧传感和已下发历史生成当前动作及续行动作的菜单。完整 production governor 与 ICS 验证原动作，非零变化至多 0.30 米/秒。各对同时检查 1.0 秒保持、0.90 秒转零后备、原观察路径与新近场转零余量，均守 0.39 米。保存原保护和紧急优先级。每拍续行动作只作下一拍提示，须使用下一拍扫描重证。

两个评分臂共用同一个发车动作。引导臂用离线物理序列给同一当前菜单排序，保持臂仅用上一拍获证的续行方向并用 IMU 转到当前机体系。引导臂用于诊断物理轨迹的精确提示能否弥补门控，保持臂的续行排序不读取未来原件。两臂都从登记拍候选启动，暂未实现一般触发。原始零令只允许实际下发零，所有失证转零按前一证书窗口、生产限幅与当拍近场条件验证，遇原保护可立即交回。最多尝试至第 1090 拍。尺度、回放场景、正式评分和资源底线由上一轮冻结输入给出。

读取实际世界系与机体系下发，按 5 毫秒复核完整观察段的净空，并保留松杆漂移、停稳时延和登记恢复。只有场景配对守住门槛才考虑扩检其他来物和响应。
