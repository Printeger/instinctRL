# 相邻分支拍与传感器同历史核对

补测第 1065 和 1067 拍，使用已登记的动作约束与同一正扰动前缀。另从第 1060 至 1070 拍用逐组共同执行前缀重建当前传感器输入，所有来物配对均固定为同一初态姿态。记录最近四帧是否逐元素相同、实收深度变化、现有配准是否成功、配准中心及速度投影。方向固定为本试验扰动轴，用于离线比对。输入只用实际四帧测量、指令、重力和已下发动作。仿真真值供渲染与离线比较使用。

每侧配准中心保留原模型 1 毫米误差量。组间速度区间按两个点的误差和实际采样间隔放宽。在同历史时，离线分组标签上的不同处置只能作为物理诊断。配对出现深度差异只界定传感器差异最早可能到达的拍位，组间区间仍须足以支持真实的因果分支。
