# 松杆前的来物分支时机

固定上一轮达到净空门槛的正扰动序列。原来物及负扰动组从指定分支拍起可以改动松杆前和恢复后的动作，同一组共用一条序列。分别允许在第 1068、1066、1064、1061 拍分支。每个分支用八个预定起始方向，保持三级响应、全程零令窗、0.20 米漂移及松杆一秒后 0.07 米/秒条件。初始执行状态、分支前指令和最终接回原 CCG 的时钟完全一致。非零动作单拍变化至多 0.30 米/秒，进入松杆的直接转零和第 1084 拍可直接从零重新介入，沿用上一轮两处诊断性特例。

逐 5 毫秒复算物理与静态净空至第 1149 拍。用两组最小值判断共同物理可行性。本次分组标签来自离线真值，仅用于测试分支时机。传感器可区分性单独核对，同历史时不得为不同来物选择不同动作。
