# 联合选择共用前缀和短时保护位移

沿用冻结 v60 的首拍菜单、实测队列、五种来物、三种响应时间和静态几何。两组分别为原来物与两个负扰动，以及两个正扰动。各组的一份动作同时用于三档响应。三组实验依次执行。

1. 全程零下发的松杆窗，允许在第 1067 拍按离线组别分支。以前 17 条严格零令筛查幸存的首拍为候选，两组共同优化所有共享拍及各自后段。复用恢复首拍可直接达到 0.45 米/秒的诊断特例。
2. 允许第 1070–1073 拍在零令下保护位移，全场景共用同一动作。恢复首拍使用原 0.30 米/秒上限。首拍菜单开放全部 142 条。
3. 同样允许松杆初期保护位移，前缀在第 1067 拍前必须相同。仅从第 1067 拍按离线标签放开分支，其余条件同第二组。

第 1067 拍是提前放开的离线假设，上一轮的传感器证据尚未确认这一分组时机。每组仅允许显式转零跨越变化上限。计分以原始松杆拍为锚，从第 1080 至 1084 拍每 5 毫秒测得速度必须至多 0.07 米/秒。松杆窗最大漂移为 0.20 米，运动净空至少 0.15 米，第 1102 拍按原时钟接回 CCG，逐 5 毫秒检查至第 1149 拍。活动段松杆路径漂移也按全分辨率复核。搜索使用全轨迹真值，仅作物理筛查，找到第一条过线序列后停止该组。失败覆盖有限的求解初值和动作族。

原生 v60 收口、既有 ICS、正式停杆与恢复计分照旧。过线序列仍需证明因果分支、实际可发性和回退安全。
