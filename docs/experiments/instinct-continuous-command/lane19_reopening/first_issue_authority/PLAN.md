# 第 19 路替代首拍与松杆后的可达上界

用冻结 v60 的实收扫描、历史和原下发，复现第 1060 拍的 142 条入口证书。从冻结候选函数提取各条证书原始 governor 动作，再经原 ICS 核对实发机体系向量，保留相同首拍对应的不同续行动作。按归档姿态转换首拍到世界系，上一拍排队命令使用归档世界向量。

对每条首拍，松杆窗第 1070–1083 拍下发零。松杆前允许任意水平后续动作，最高速度 0.45 米/秒、单拍变化 0.30 米/秒，且可随时紧急转零。第 1084 拍起分别允许同限幅的任意水平恢复、第一拍即可全速的水平恢复、按相同限幅直接跟随原 CCG。通过 180 个水平投影方向求逐物理拍上界，按半格余弦修正漏采角度，保留首拍的实发垂向分量。比较原来物和四种扰动、0.25/0.35/0.45 秒响应。后续动作条件按该离线模型的世界系约束，固定姿态困难组可直接对应机体系变化数值。

上界放开后续 ICS、墙面、漂移和观测要求，每个采样点可取不同的最有利动作。任一场景或响应上界低于 0.15 米，就可排除该菜单首拍及此次续行方式。达到门槛的上界只表示需要继续找实际可发动作。使用仿真真值离线计算净空。生产控制和原生评价沿用冻结版本。
