# 第 1052 拍共用轨迹的实际下发核对

固定第 1052 拍过线的全零松杆序列。采用原来物与已登记的早分岔正扰动，均固定为同一分支姿态与 0.45 秒跟随，分别同未修改 v60 配对。从原生历史预热现有控制，对每拍目标重新计算 governor 和 ICS，保持当拍所有原保护优先级，重建路径后按批准的传感器重新取得 0.39 米保持和转零后备下界。原 ICS 输出相差超过 0.00002 米/秒、下一拍规划与当前可发量不符或任一复核失败，即记录并退回未修改 v60。原新权重、原连续指令和传感器访问边界均保持。

固定轨迹来自离线搜索，这一步只核对它的可发量与闭环证据。提前触发是否应替换 v60 的规则另行判断。结果按 5 毫秒记录净空，并保留松杆和最新指令恢复计分。
