# 墙面配准的共同视野复核

用冻结 v60 第 1060–1064 拍闭环原件，重建四帧 LiDAR、姿态、实收指令和上一拍下发。保持原移动体识别、墙面提取、三平面最低支撑、方向条件数和 1 毫米平移门槛。初始整体拟合只能用于把墙面切向坐标对到最新帧。跨四帧取共同切向和高度范围，边缘内缩 0.02 米，在固定中线两侧留 0.06 米间隔，每侧每帧至少 12 点且有足够高度。在这些先定好的独立区域内重算墙面偏移。

两侧各自的方程残差、与整体配准的差，以及重新估计与原整体配准的差都须守住 1 毫米。额外对一个指定半区和历史帧加入 6 毫米偏移作为拒绝对照。原第 1060 拍成功原件作相邻对照。第 1061 拍两臂两来物均检查。共同支撑不足或平移仍不一致时保留否决。

这是闭环原件上的 CPU 测量复算。追加方案通过独立余量和对照后，才考虑接入下一次隔离闭环，生产 v60 保持冻结。
