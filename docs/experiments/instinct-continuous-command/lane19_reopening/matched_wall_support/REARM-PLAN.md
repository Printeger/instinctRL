# 转零后备期间用新证据重新接续

第 1061 拍共同视野不足，继续原有零动作和时限。第 1063 拍两条引导轨迹的同墙面半区通过 1 毫米门槛，并拒绝指定的偏移对照。允许在原转零后备尚有效时用新扫描重新接续。两臂分别只使用原注册、以及原注册不成立时使用同区域复核。固定第 1052 拍起步、引导评分、原保护优先级、完整 governor 与 ICS、原保持和后备净空证书以及固定姿态和 0.45 秒简化跟随。

对原来物和早分岔正扰动各跑一次每臂，直到第 1062 拍的实发须同上轮完全匹配。仅在原来物与扰动的共同输入闭环净空、松杆和恢复守住原门槛时扩检其他响应。回放中的原生 v60 控制保持冻结，新增配准仅用于诊断性续行计算。
