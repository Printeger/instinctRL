# 第 19 路续证失败后的有限转零

冻结上轮困难配对的 v60 源码、权重、输入、CPU 回放和整条旧交接轨迹。新臂在失证前须逐拍复现旧臂，包含动作、下发、机体平移和测量响应。只在获得上一拍动态证书且独立复算近场静态余量后，测试按证书下发零。证书假设一拍候选、随后零，时长从原证书拍起算 0.90 秒。队列有一拍，之后到期交回 v60 观察余下轨迹。

每拍保留独立的 v60 更高保护和紧急判定，并用完整 ICS 验证最终下发确为零。即停在这一项 CPU 诊断中沿用现有 mover 回退的零动作，允许从 0.450 米/秒直接下发零。其余换向和避让仍用原首拍变化上限。重证的最新回波距离须扣除最大跟随漂移、队列、首拍移动与 0.055 米余量后仍达到 0.39 米。该近场检查只约束可见回波，离线几何和来物真值用于物理包络计分。

困难组先做一次，原来物组做一次作为对照。分别报告证书有效期及余下轨迹的最低净空、晚段零指令停稳和漂移、登记恢复与可行跟踪。安全标准仍为 0.15 米。使用冻结的 0.35 秒模型和归档路径，CPU 诊断不会启动原生评价或训练。
