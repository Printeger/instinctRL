# 街道第 19 路的第 1060 拍 CPU 闭环

沿用 NOVEL-115 原扫描、原 Crazy Command Generator 指令和冻结 B 权重，从第 979 拍预热 v60 执行状态，第 1060 拍按原状态分支。试验臂复算早启菜单，从完整 ICS 下发保留获证的原动作，后续只有重新满足静态、1.0 秒保持路径、0.90 秒转零后备净空下界 0.39 米，才替换原控制动作。优先把控制交回经复核并跟住最新指令的原动作。零指令时优先发获证的零动作。新证缺失时交回未修改的 v60，记下交回原因和此后的净空。首拍两臂的实发量和试验臂所选原动作必须与原件及已登记证书对应。

同时测量原配置和试验臂在记录姿态、原横穿轨迹上的表现，再做已知困难的固定姿态、正向扰动配对。扰动在原第 1064 拍之后分岔，沿东北向叠加平滑的 0.22 米/秒² 加速度。两条配对均用 0.35 秒响应和一个控制拍的排队。两项通过后才扩到登记的反向和早分岔对照。场景真值仅用于重建传感器回波和离线计分。

逐 5 毫秒记下净空，检查 0.15 米门槛。第 1070 至 1083 拍为晚段诊断松杆窗，短于登记停杆所需的 2 秒，另报持续低于 0.07 米/秒的首次时延和最大漂移。正式登记恢复共钟仍为第 1110 拍，按最新可行指令方向的实测进展连续五拍达到 60% 确认，最迟为第 1124 拍。记录至第 1148 拍，给最后一个可判定拍提供原计分器需用的 2.4 秒来物预报。CPU 位移采用简化响应，下一拍姿态采用归档姿态或在分支时固定，不运行原生 Isaac 仿真。
