# 横穿前建立可刹停的横向净空

NOVEL-33 在街道 lane 19 避开接触，最小物理净空仍只有 0.05439 米。第 1,068 拍的原沿向动作只是延长追近时间。第 1,075 拍实际改为西斜移，交会前建立的横向距离仍低于门槛。 [前次同输入结果](../finite_intercept/REPORT.md)

回放复算第 1,068 拍，提前向横穿方向的侧后方下发约 `[+0.295, −0.052, 0]` m/s，原 governor 与 ICS 的 β 为 1。离线保持 3 秒后制动，5 秒物理投影最低 0.421 米。第 1,074 拍同类动作另有 0.298 米投影。实际闭环可能因后续测距与保护重新评估而改变。

候选仅在零令且四帧曲面拟合显示继续停止有冲突时评估。原 governor 与 ICS 逐拍审核两侧的反斜向与上一可用方向。用已下发命令的响应及有效回波复核保持 2.6 秒再刹停的运动，并要求停后与拟合横穿线同侧、仍有净空。三项测量下界都到 0.39 米、当前替代动作仍未达到此值且保守改善至少 0.075 米，才选择新方向。续持仍经原 governor、ICS 与四拍上限。
