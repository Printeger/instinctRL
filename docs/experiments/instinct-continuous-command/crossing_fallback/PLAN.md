# 临近横穿时的备选斜向与松杆复核

NOVEL-28 清除了 lane 16 早期接触。lane 20 在 58.985 秒产生新接触。第 558 拍已有有效四帧来物拟合，原动作预测净空约 0.093 m，现有方向均未达 0.28 m。第 568 拍转入刹停，实际下发为零，来物仍沿原路线靠近。

仅在已有新来物拟合、原动作预测净空低于 0.21 m、原候选均未通过时，追加两个侧向候选，各含沿来物运动反方向的 0.22 比例分量。新增动作模长为 0.2999 m/s，使浮点编码后仍在 ICS 的 0.30 m/s 上限内。备选继续经原 governor 和 ICS，采用原绝对净空与增益门槛。原来物关联、紧急零令和已选方向的复核照原规则执行。冻结轨迹 CPU 对照表明候选可在第 558–571 拍依次经原 ICS 下发，闭环效应由同输入实测判断。

对同一持续零令，保持已经从一次松杆触发的净空复核，直到原撤离停止、原适用条件失效或指令变化。每拍仍需通过原可靠性与净空证据。lane 20 首个停杆窗中，原净空证据到第 138 拍才首次通过，短复核窗口此前已结束，原物理零令扫掠下界 0.543 m。
