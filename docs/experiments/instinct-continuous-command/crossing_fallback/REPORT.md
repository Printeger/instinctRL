# 横穿备选斜向与持续松杆复核

NOVEL-29 全部 32 条完成首飞 120 秒，累计 3,840 模拟秒，零接触、零中途重置，32 个预设松杆窗全部通过。全轮 5 ms 最低净空为 0.198 m，出现在街道 lane 22 的 85.845 秒。lane 16 早期原接触窗的最低来物净空保持 0.381 m。lane 20 实际在 0.8 秒停稳，漂移 0.179 m，后段原接触窗的来物净空达到 1.314 m。两项修改都能改变后续姿态和暴露，闭环记录无法将后段收益全归给斜向。 [逐类结果、来源和关闭回执](RESULT.json)
