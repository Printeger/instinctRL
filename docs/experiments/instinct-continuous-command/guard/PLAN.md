# 同权重提前制动对照

[B/C 连续基线](../BASELINE.md) 两个权重都在名义重合组的街道 8/8 接触。两条对照显示回波和底层刹停正常，先前逃逸的顺指令加速可能把机体带入来物扫掠范围。只使用 B，场景、种子、时间戳和三种横穿时刻与 PAIR-04 相同。每条执行臂均重新运行 3 × 32 × 180 拍。控制使用原 B 执行配置，候选仅加入首拍超速触发的原时长制动。两臂用同一权重文件。候选在原逃逸首拍如可下发的速度沿当前人令方向超过人令 0.02 m/s，则将该次逃逸的动作设为零目标速度，并仍经过原 governor 和 ICS。保持期结束后走现有最新指令恢复。触发不使用场景标签、机体真速度或来物真值。

比较沿指令轴的早期位移、实际接触、首飞风险窗是否覆盖最新换向、解除后的下发与进展。阶段成功需要两个横穿场景各 0/8 接触且全 lane 无新增接触或提前终止。无横穿时不允许新制动，原跟踪与停止结果保持同等。观察到碰撞或持续无进展则留原件，依据逐拍证据决定下一版。开发改善之后仍需新场景、范围更广的回归和真正独立留出。当前原三臂保留名义时刻与实测重合的区别。

单次总计 34,560 个评价步，模拟器一次初始化，上限 1,200 s，系统分区 payload 512 MiB，30 GiB 余量。只预留一次实际闭环，不含训练。普通目录与输入约束沿用 R6 直接入口。前驱为已关闭的 PAIR-04。
