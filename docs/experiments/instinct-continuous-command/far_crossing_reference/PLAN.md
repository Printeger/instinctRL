# 远距横穿方向的同输入修复

街道轨迹 20 在第 1092 拍把向西的请求判成接近横穿线，转向东并续发四拍。其后同侧拦截一度拉开距离，第 1122 拍起已很难继续建立余量。第 1143 拍的物理净空降到 0.05257 米。原始远距拟合在横向上多估约 0.041 米每秒，导致预估落在横穿线的错误一侧。相同远距回波的四帧测距以独立平面复核后，横向分量接近零。 [原轨迹](../hover_escape_own_side/REPORT.md)

只对首次远距预判且横穿线偏移不超过 0.28 米的情况，用原拟合的远距回波种子做静态平面复核。一旦缺少四帧同时支持的平面，沿用原轨迹拟合。保持原有下发、停驻与净空门槛。首批固定 B `u2816` 以及第 55 批的几何、Crazy 指令、横穿时钟、扰动和停车窗。记录两处问题窗口、全部 32 条首飞和五类最低物理净空。 [正式门槛](../long/GATES.json) [预登记独立复验](../independent_far_crossing_reference/PLAN.md)
