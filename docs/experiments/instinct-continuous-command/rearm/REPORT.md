# 近险后暂缓回中补偿的结果

两臂共完成 70,400 个 PhysX 评价步。回中暂缓候选 32/32 条首飞全部飞满 110 s，零接触、零重置。对照复现上一轮街道 lane 23 在第 1091 拍的接触，除了全局物理拍的固定偏移，逐拍原件完全一致。五个冻结推进窗口结果相同。候选的最小 5 ms 包络净空由 −0.09659 m 改善至 −0.05065 m，仍未达到正净空。 [逐类结果与原件](RESULT.json)

原补偿第 1074–1078 拍连续推进。候选这一段保持原位到第 1078 拍，但已有逃逸随后仍以约 (+0.165, −0.251) m/s 向横穿平面斜移。根据该拍实收测距和控制链复算，原向、径向退避和逆当前命令三种均可下发。由最新两段观测估计的最近回波距离分别为 0.135、0.454、0.473 m。三种预测距离用于比较方向。实际净空和接触用下一轮物理闭环判断。 [折返选向配对](../rank/PLAN.md)
