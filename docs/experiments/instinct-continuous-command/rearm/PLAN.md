# 近险之后的回中补偿配对

复用 PASSAGE-01 的 110 s Crazy Command Generator、B 权重、场景和扰动。两臂都保留按 LiDAR 判断的零令保持。候选只在最近可信回波触及原紧急制动阈值后的 1.0 s 内暂缓额外的回中补偿。在此期间策略、当前指令和既有保护仍按正常路径下发，提前撤离、逃逸与紧急制动的判定保持原配置。

PASSAGE-01 街道 lane 23 于第 1091 拍接触。此前第 1074–1078 拍原 actor 速度会被 ICS 裁零，额外回中补偿却转为有向前分量的斜移。随后横穿物反向，第 1079 拍既有逃逸继续向横穿平面推进。新配对用于隔离先发生的回中动作。后续既有逃逸与原停位贴近横穿路径也是独立风险，因此必须跑到第 110 秒并复算该段净空。

两臂都保存 5 ms 净空和策略拍完整原件。检查第 1074–1078 拍补偿、紧接着的真实位移、再入险和接触，并检查其他布局的安全、推进和恢复。两臂共 70,400 个 PhysX 评价步，单次初始化，工作负载上限 1,800 s，结果上限 512 MiB，系统盘保留 30 GiB。本轮为开发评价。
