# 水平保护命令的高度偏差

`LONG-01` 走廊第 26 路从 1.95 米飞到 0.499912 米，在 1,370.7 秒触发高度重置。原始 Crazy 指令在首飞 13,707 拍均为水平。策略自身的世界系竖直命令积分为 +0.367 米。保护层选向和末端限幅后，实际下发竖直积分为 −0.811 米。实际高度下降 1.450 米，留下 −0.639 米的飞控响应差值。普通避让期间，下发与实测各下降约 0.974 和 0.976 米。走廊第 27 路也在 1,569.8 秒跌破高度线。 [高度与下发的时间轴](CPU-WITNESSES.json)

`v44` 用已有的最新机体重力测量，在 ICS 前将机体系纯平面保护动作投影到水平面。选向候选和最终控制用同一变换。显式升降、已含竖直分量的保护动作和常规策略下发仍由原逻辑处理。原末端的竖直速度飞控、物理停止条件和验收门槛继续沿用。

在实际控制入口固定重放重置前七拍，最大横向变化为 `2.99e−8` 米每秒，候选竖直下发绝对值均低于 `5e−10` 米每秒，ICS 两臂均完全放行。走廊较早的受阻反例保持零下发。锁定已观测残差的全前缀复算，把第 26 路模型最低高度由 0.499912 提至 0.901 米。此项复算保留原机体响应，候选的完整飞行高度将由原生回放测量。 [逐拍重放和全组固定前缀](CPU-WITNESSES.json)

街道第 22 路既有横穿修复窗口在 0.45 秒模型响应下仍高于 0.38 米净空。室内和管道的三处指令交回窗口保持沿令达标拍数。第二阶段 420 秒原生配对沿用 `v44` 的重力对齐，同时复验横穿、交回及停杆。 [配对方案](../static_retreat_handoff/PLAN.md)
