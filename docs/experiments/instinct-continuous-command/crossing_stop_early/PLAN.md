# 远端横穿轨迹的提前撤离

同输入 NOVEL-36 将原近距恢复到 0.10815 米，仍未达到要求。等到首次零令才开始避让时，东侧两次受到已观测墙角限制。把早期识别仅用于可靠的四帧远端曲面，可在第 1,054 拍已经看到横穿体，较第 1,068 拍提前 1.4 秒。此时既有指令向来物运动线推进，保持 0.6 秒再制动的预测曲面间距为 −0.322 米。计入只会减小余量的排队指令和惯性后，机体仍在原侧。 [上一轮对照](../crossing_stop_shallow/REPORT.md)

新增介入使用当前测距、时间、IMU、当前及历史下发命令。仅在四帧支持 1.90–2.65 米的新鲜运动曲面、最新和可下发意图正在向其运动线推进、预计 5.5 秒内经过且短移刹停有冲突时，尝试原侧撤离。原 governor 和 ICS 继续审查。保持 2.6 秒再制动的预览要求测距、停后同侧和来物速度扰动扫掠均至少 0.39 米。测距仍可支持同侧动作时逐拍复核，缺少新观测沿用原有四拍上限。最新指令可行时回到原控制链。

原范围识别、接触和净空验收要求仍沿用冻结方案。两种姿态离线复核经过 22 个有效拍后的 5 秒保守物理下界为 0.218 米；逐帧再选择的两种预览约为 0.356、0.360 米。这些数值来自重建测距与近似动力学。真实匹配复验须核对 32 条完整首飞、两个街道窗口、0.15 米净空、过门过角与全部预设松杆。 [原验收门槛](../long/GATES.json)
