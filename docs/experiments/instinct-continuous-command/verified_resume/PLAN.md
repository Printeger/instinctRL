# 用两次独立测距复核恢复当前请求

NOVEL-16 的街道归档里，lane 18 第 316 拍的原 actor 动作可以通过当前 ICS，持续请求扫掠的物理净空却为 −0.257 m，推进再停也只有 0.036 m。第 317 拍最新请求转为横向，按实速和来物复算，交回原动作净空为 0.190 m，原制动仍持续。另有单次移动拟合给出 0.590 m 表面距离、持续扫掠只余 0.092 m 的反例。原闭环均未接触。 [CPU 回放与反例](CPU-WITNESSES.json)

候选读取当前低速请求，在已保持撤离或制动时，要求前向回波覆盖、原 governor 和 ICS 放行并实际增加沿令进展。用现有四帧关联估算来物路径，按将要下发的动作复核其最小表面距离至少 0.48 m。没有支持的移动关联时，仍须符合四帧覆盖、距离和无闭合见证的现有规则。连续两拍均支持且请求变化不超过 0.04 m/s 才交回原 actor 动作。最终移动体保护仍逐拍判定。1,696 个旧保持拍复算，564 个满足两次确认，最小物理扫掠净空为 0.197 m。

用相同 B 权重、场景、120 秒 Crazy 指令、横穿和脉冲执行一个新候选臂，共 38,400 个实际评价步。与已关闭的 NOVEL-20 同输入候选原件配对，逐场景记录 5 ms 净空、接触、重置、预先登记停止窗及按正式定义计时的恢复。冻结对照原件与新执行配置属于开发比较。独立几何和正式 R6 完整配置沿既有方案。 [对照](../rotation_tube/PLAN.md) · [独立复验](../independent_second/PLAN.md)
