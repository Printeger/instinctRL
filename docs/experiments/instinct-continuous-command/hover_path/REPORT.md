# 零令逃逸路径核对的 110 秒结果

两臂 64 条首飞均飞满 110 s，零接触、零提前终止、零重置。候选的 5 ms 最小机体包络净空为 +0.15703 m，出现在街道 lane 19 第 96.790 s。对照最差为 −0.01824 m。室内、树林、走廊、管道下发逐拍相同，五个预登记推进窗口结果也相同。 [逐类结果与原件](RESULT.json)

街道 lane 19 第 1012 拍、lane 23 第 1022 拍原逃逸会让机体靠近横穿平面，候选选择停留。较早的 lane 17、21 第 152 拍保持原下发，两条轨迹避开了直接曲面保持对照中的新增接触。当前已达到这批开发轨迹的 0.15 m 净空检查值。松杆漂移、长时独立留出与完整 R6 仍待验证。 [松杆配对](../stop_release/PLAN.md)
