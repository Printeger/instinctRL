# 零令时核对旧逃逸路径的配对

同 B 权重、110 s Crazy Command Generator、五布局和物理种子。对照使用 RANK-01 的折返选向候选。两臂沿用相同的旧零令保持判定。实验臂仅在可信曲面回波显示旧零令逃逸会让预测表面距离不足 0.45 m 时，比较停止、径向退避和两个切向。现有 governor 和 ICS 实际允许的速度用于比较。预测改善至少 0.08 m 才调整。停止预测余量达到 0.45 m 时优先停留。观测模型结合最近四帧的测距、IMU 和已经下发的命令，按已冻结的响应近似估计既有运动的惯性。整段物理轨迹由 PhysX 独立评价。

两类对照原件提供区分。RANK-01 街道 lane 23 第 1022 拍，原逃逸预测表面余量约 −0.006 m，停止约 0.661 m。相对地，lane 17 和 21 第 152 拍原逃逸的余量各为 0.686、0.708 m，原方向会保留。CURVED-01 在这两条轨迹的更早时刻改了停留决定，后来出现接触。验证比较动作是否只在原预测路径迫近时变化，并核对逐 5 ms 净空、漂移和原推进窗口。

两臂共 70,400 个 PhysX 评价步，单次初始化，工作负载上限 1,800 s，结果上限 512 MiB，系统盘保留 30 GiB。只用于开发评价。
