# 实测弯曲横穿的提前选向配对

复放独立回放 N108 的原权重、原场景、原 Crazy 指令和脉冲。N108 作为这次开发配对的冻结对照。新候选率先验证街道第 20 路的接触比较，保留其余低净空和松杆失败。 [原对照](../independent_observable_sweep/REPORT.md)

新增保护使用四帧实收测距、帧时标、陀螺和下发历史。建立可关联的曲面，同时出现两段同向加速度且原动作风险存在时，在原 ICS 可下发方向中选取有余量的动作。起始候选验证实测障碍表面模型的 0.39 米门槛和沿最新请求的进展。最多 24 拍，横向加速度出现新的持续改变时重新选向。候选逐拍继续受原 ICS 和现有优先级约束。对已经改变的请求，若原控制可下发并沿当拍请求推进，当拍交回。全程不向 actor 添加输入。

第 20 路的初始离线证据保留固定旧转轴的有效域。相同可见历史之后，额外平滑横向转弯可使固定方向失守。该反例用于 CPU 闭环检验新来物证据和重新选向。用最小模型余量为再选排序，实际 0.15 米物理下界仍由原生配对复算。左转、右转、不可判别与急停止均不读取未来指令或场景成员身份。

本轮 32 路各 120 秒，38,400 个评价步，一次显式初始化，零训练。对照与候选比较街道第 20 路、其余三条低净空、全部窗的实际松杆、最差跟踪和最新请求恢复。经过模型闭环筛查后获得的匹配轨迹只提供开发证据。正式门槛沿用已有登记。 [正式阈值](../long/GATES.json)
