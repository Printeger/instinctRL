# 室内门洞到转角的指令时序对照

110 s 开发对照两臂门洞均 8/8，转角均 1/8。原室内指令在第 14.5 s 开始横移，当时多数机体仍在门洞或门洞附近。先排查这段路线的转向时机。两臂都用 B 权重和提前撤离配置，场景、往返来物、种子及其他布局的命令相同。实验臂室内前飞延长到 20.0 s，随后向开口横移至 27.8 s，再向前越过转角平面。生成器从 42.0 s 启动的随机段完全相同。两臂向量都有时间戳，运行期间不按位置触发任何命令。

分别复算越过门洞、横移段末位置、转角通过、接触、连续首飞时长及转向后推进。逐拍比较其他布局的下发和实际运动。彼此仅用于定位当前开发路线，正式留出须使用独立场景和生成输入。

两臂各 62 s，共 39,680 个 PhysX 评价步。单次初始化，总计两个显式重置，工作负载 1,200 s 和 512 MiB 结果上限，系统盘保留 30 GiB。没有新的训练步。
