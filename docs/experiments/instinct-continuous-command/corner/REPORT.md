# 室内转角指令时序对照结果

同 B 权重与提前撤离配置。室内延后横移后，62 s 内通过转角从 0/8 增至 5/8。第 38.9 s 前的指定转向和前飞序列直接通过 1/8，另四条在第 42 s 之后的同种子生成命令期间通过。两臂门洞均 8/8，共 64 条首飞飞满 62 s，零接触、零重置。其他四类布局的指令、实收、下发、实际运动和接触逐拍相同。 [原件及逐 lane 索引](RESULT.json)

剩余三条在转向后的首段前飞均遭遇无急停的 ICS 归零。横移结束时，lane 3、6、7 的横向位置约为 0.54、0.82、0.90 m，角沿在 0.55 m。实验臂的室内最小策略拍包络净空估计 0.438 m，原时序为 0.375 m。这轮验证了既有时序会让多条轨迹在门口过早横移，也保留了延长前飞后仍未过角的实例。

对转向后前飞的 888 拍重建射线，原 0.60 m 扫掠半径的裁零系数逐拍复现。0.52 m 和 0.47 m 不改变这一段的下发。0.42 m 会释放 lane 0 和 lane 2 的 193 个裁零拍，另外三条未过角的轨迹仍受阻。Lane 6、7 在横移末段还有一处独立卡点，距请求方向横向约 0.89–0.91 m 的门框回波缺两段有效历史。该证据支持区别角沿余量和新显露门框，再决定是否改变保护层。 [射线复算](LIMITER-SHADOW.json)
