# 窄长实测走廊内的垂向补偿

`v51` 的垂向投影改善了四条走廊高度，街道第 21 路出现净空和停杆退化。最早的重要轨迹分歧发生在第 869–875 拍。离线重建表明，约 2.7 毫米的水平位置变化足以切换当时的保护选向。第 1000 拍停车缺证与第 1114 拍撤离方向丢失分别形成两个后续失败。

`v53` 在 `v52` 上仅限实测窄长双墙环境使用同一底层补偿。三帧对向垂直面需提供 1.65–2.26 米宽度，以及各自连续覆盖 3 米的沿墙区间。宽度每秒重证，当前扫掠失效、过期、明显转动或已选择来物保护时暂停。测距、有效性与 IMU 来自原有观测；布局编号不参与控制。底层的 5°、0.03 米每二次方秒、2% 转子余量和原力矩边界照旧。

原回放和独立双轴折返回放的初飞样本各有 48 组走廊数据，96 组均获得窄长墙面证明。其余共 656 组未获证明。用 `NOVEL-106` 的同一 B `u2816`、五类 32 路原 Crazy 指令、几何与初始条件，原生配对前 120 秒，检查每路实际补偿、终点高度、净空、停杆和沿当前指令的进展。评价 38,400 步、一次显式初始化、零训练，墙钟 1,200 秒，载荷 512 MiB。 [垂向失败对照](../collective_projection/REPORT.md) · [正式门槛](../long/GATES.json)
