# 转角开口的选向配对

室内 lane 0 在第 287 拍进入普通逃逸，之后向开口反侧移动 25 拍。三帧测距已共同支持正前方约 1.39 m 的宽平面和一侧更深的 30 个回波方位列。另一侧没有同类证据。左右镜像斜向都通过原 ICS，按物理轨迹和场景复算，朝开口运动穿过分隔面后的最低包络净空为 +0.567 m，另一侧为 −0.222 m。这些投影仅作为设计依据。

只在已有普通逃逸起点、当前请求稳定、三帧可靠测距同时支持同一正前方面和单侧深处开口、且原选向指向反侧时，试向开口斜移。速度模长受当前请求和原上限约束，保留原 governor、ICS 和来物保护。下一次用户改向或松杆时结束此次选向并评估最新请求。保留同一门框处理和验收门槛。
