# Crazy 指令下的同权重扫掠范围对照

当前验收范围按用户要求限定在仿真，独立指令来自 crazy command generator。使用 [五布局路线](../routes/STREAMS.json) 作为 42 s 复现前缀，随后以固定种子 725 连续生成 20 s 压力指令。每种布局都有一至四秒保持的正常移动、急变、预定威胁方向、振荡及零令。机制沿用历史对抗指令生成器的五个模式和持续时间，方向来自冻结场景方案。生成器与实时机体和障碍真值隔离。

固定 B 权重、同配置的提前制动作为对照。候选只改变 ICS 中低速、具有可靠时间历史的侧向回波参与条件。半径 0.60 m 内仍参与原径向限速。更快的异常逼近、历史缺失、较旧数据保留原行为，全方向紧急阈值保持既有设置。候选仅使用 LiDAR 历史、当前请求与已标定射线。保留实际限制束和体坐标命中点供复算。

五布局原件已定位门洞和走廊侧向回波造成的裁零。候选要改善门洞实际通过数和走廊轴向进展，同时守住接触、提前终止与现有移动体让行。单独检查保护是否继续阻止撞向真实墙面，并报告最差轨迹。当前只做开发对照。正式长期独立生成指令、场景、运动扰动、最低有效危险事件和逐项门槛将在首次正式评价前另行冻结。

两执行臂各 32 条 62 s 实际飞行槽位，共 39,680 个物理评价步，单次模拟器初始化。墙钟上限 1,200 s，payload 512 MiB，系统分区保留 30 GiB。无训练。
