# 62 秒 Crazy 指令开发对照

两臂各 32 条首飞均完整飞满 62 s，共 **39,680** 个真实 PhysX 步。两臂零接触、零提前终止、零重置。带风险实际换向均为 8/8。相同 B 权重、场景和输入下，扫掠范围 v1 将门洞通过从 1/8 提高到 8/8。转角通过从 0/8 提高到 1/8。走廊平均最远轴向位置由 1.72 m 增至 4.98 m。 [逐布局原件与复算](RESULT.json)
