# 让有可见净空的门框路径继续前进

候选沿用正向 0.80 m 停止距离、0.15 m 余量、全方向紧急停车和既有行动审查。对会限速的侧缘回波，允许有效扫掠半径使用 0.41 m，前提是三帧近轴确有越过 1.10 m 的远端回波，两侧每帧各至少三列，并且三帧均无可靠回波进入轴芯。侧缘自身也须有三帧有效、时钟新鲜、转动较小、与当前请求一致的距离变化。无回波不计支持。

相邻历史候选的同状态复算中，室内 lane 0 有 41 个抽样拍可通过，按 1.2 s 下发再刹停的估计包络净空最低为 0.395 m。室内 lane 1 和 lane 7 在各自见证窗缺乏足够轴芯净空，保留原制动。走廊、管道和街道见证窗保持原动作。冻结前以原 R6 墙面测距核对真迎墙否决。 [几何与墙面原件](CPU-WITNESSES.json)

复用同一 B 权重、32 路 Crazy 指令、初态、横穿与物理扰动。两臂各飞 120 秒，总计 76,800 个评价转换，工作负载上限 1,800 秒，512 MiB 输出上限及 30 GiB 系统盘余量。实际首飞逐类审查推进、门角通过、松杆、接触和 5 ms 包络净空。
