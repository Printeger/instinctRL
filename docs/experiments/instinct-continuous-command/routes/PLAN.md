# 五种开发路线的连续闭环基线

保留 B、C 的原权重和执行，并加入同 B 权重的提前制动候选。每种布局设独立的 42 s 开发指令。先前脚本未到门洞与转角，这批室内指令穿过 x=2.1 m 的门洞，侧向进入内角外侧，继续越过 x=4.1 m。树林在首个前侧树干之前斜入、横移离开并继续沿树列通行。街道在新种子上复现名义重合横穿，随后继续前行、横移和反向。走廊与管道各有沿轴、横向、反向及零令停留。所有计算阈值均用于开发诊断。

场景中的 32 条物理轨迹分为 8 室内、8 树林、8 街道、4 走廊、4 管道。每种权重运行 42 s，不在指令间重置。换向后结束首飞时保留接触和原件，后续自动重置样本只作诊断。独立按布局报告接触、实际累计进展、最小射线以及停止速度与漂移。室内按真实轨迹检查是否实际越过两个地标。走廊和管道的横移是否得到安全响应仍须用实物轨迹判定。 [冻结指令](STREAMS.json)

一次模拟器初始化、40,320 个物理评价步、上限 1,200 s，系统分区 payload 512 MiB，保留 30 GiB。未纳入训练。跑完后依据原件确认实际覆盖、最差轨迹与下一轮的独立开发布局。
