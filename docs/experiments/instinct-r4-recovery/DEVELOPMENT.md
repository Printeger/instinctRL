# R4 后管道恢复开发对照

当前任务授权固定权重物理对照、短 PPO、单候选新增 1,024 次 PPO 更新及两套独立评价。先沿用 `u640` 和批准的 LiDAR、IMU、测量历史及操作者速度指令。仿真真值仅用于既有 reward、critic、评价、日志和飞控途径。旧合格权重保留为产品基线。

## 首次物理对照

开发种子为 `184976539`。三臂共享同一 `u640`、管道和移动体。对照臂保留二十五步 R4 侧让。第二臂在 ICS 放行且保留横向分量时加入四分之一指令。第三臂在此基础上，对侧让结束后仍被裁零的前进请求，检查通过原 governor 和 ICS 的带侧向分量的动作。原 ICS 紧急停车和控制器继续裁决每次请求。等权重、同环境的静态通行和静止悬停核对退化。

管道前飞的全部八个初始配对均进入结果。第 80–119 步实际轴向位移达 0.5 m 且全程无碰撞计为恢复。逐 lane 检查新增接触、原请求、侧让持续时间、实际下发、横向位移、恢复进度及速度跟踪。碰撞结束的轨迹仍计入分母。固定权重至少复现一次恢复提升后才进入短 PPO。后向独立开发配对保持同一权重、R4 侧让、无指令和同几何的来向，改变机体朝向并核对回波至侧让及接触的时间、横向下发积分和实际横移。

短训保持与计划正式运行相同权重起点和执行版本。正式方案另行冻结训练配方、段间恢复、端点与两套独立评价。开发种子不用于正式留出。作业独占单个 GPU，原件和 native 文件写入 `~/instinctrl-runs/<run-id>/`。依据实际空间和入场上限保留 30 GiB 系统盘。
