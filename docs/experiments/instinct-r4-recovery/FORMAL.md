# 管道恢复方案正式训练和独立评价

检验在已验证的动作回切上，添加真实轴向逼近课程的 PPO 续训能否进一步增加过障后的进度，同时保护物理接触、普通跟踪和静止悬停。正式起点为共同 `u640`，继承 actor、critic、Adam 及计数。新训练种子为 2026112502，首段建立独立随机流。其后按完整 checkpoint 恢复 actor、critic、Adam、计数及 RNG，重新初始化物理环境和短动作记忆。

同一候选新增 1,024 次 PPO 更新及 524,288 条转换。每次 32 环境、每环境 16 步。八段各 128 次，每段先用 64 次管道和移动体配方，再用 64 次原始命令日程。学习率和动作执行与短训相同。每 64 次保存恢复权重，段末复算计数、首批 512 样本概率、各状态抽样及原始测量。预先指定第八段的 `u1664` 作为评价端点。

R6 用原五项和十六项固定扰动块，三臂使用共同种子 1763541728，分别为旧合格模型、同执行选项的 `u640` 和 `u1664`。固定块 32/32 和最差配对速度跟踪 RMSE 增量至多 0.010 m/s 作为工程门槛，另列停令锚误差和真实水平漂移。四类独立物理留出采用种子 1657421097，开发检查使用其他随机流。门洞、树干、街道缺口和开口管道各八个几何变体，六类行为共享初始状态配对。

留出逐布局报告接触、净空、实际轴向进度、跟踪 RMSE、静止最大漂移、第 80–119 步恢复进度，以及无接触且恢复行程至少 0.5 m 的联合终点。将接触放入固定分母。保留前向、后向和非零指令各组统计。沿用 R4 工程参考，前向总碰撞不高于旧合格臂的半数且没有新增接触，静态通行 ≥旧合格臂的 95% 且 ≥1.5 m，RMSE 增量 ≤0.010 m/s，静止最大水平漂移的布局均值增量 ≤5 mm。前飞避让的进度占普通通行的 90% 作为恢复参考。

正式发车前以短训练的真实占量和时长核对八段与评价预算。GPU 串行准入，实时保留 30 GiB 系统盘。保留原始日志、恢复文件和独立 CPU 复算。旧合格产品权重与 R4 对照均按原绑定保存。
