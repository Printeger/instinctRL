# 第三轮训练设计

保留第二轮课程的条件是相对于第一轮只丢帧参考的配对护栏通过，包含硬安全项、干净停令误差、可用覆盖率和跟踪误差。若任一项超限，从 u640 重新走只丢帧课程。

从 M4 中取相邻两个采样时刻，按采集间隔而非统一步长计算相对测距变化。仅在当前请求方向内三个邻近的高可靠性回波同时逼近时，按预测的越过安全距离剩余时间给予辅助损失。明显旋转、过旧、重复送达及显著不连续的测距对均跳过。损失只对 actor 的指令增益施加软上限。这个训练信号借鉴昆虫对逼近物体的反应选择性。 [蝗虫逼近敏感神经元实验](https://www.nature.com/articles/nature01190)

解析诊断由同一份最新扫描搭配逼近、静止和远离的历史，覆盖室内门洞、树干状离散障碍、街道中的纵向移动物体、管道端壁与均匀管段。横穿物体按其实际侧向运动单独记录。先测 actor 的前进速度差，再测经过原安全护栏后的差。两者均为固定输入下的单步比较。闭环回归使用已揭晓的原评价流。
