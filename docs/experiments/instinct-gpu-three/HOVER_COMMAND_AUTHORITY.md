# 悬停时的历史敏感度与指令可执行范围

第二轮扰动前的 `u704`、第一轮 `u768` 和冻结对照在零指令下比较了 48 组同最新扫描、不同过去历史的 CPU 夹具。其中 32 组有纵向逼近、静止和远离条件。逼近减远离的前向速度差均值在三个模型中绝对值均低于 0.001 mm/s，ICS 前后相同。`u704` 的静止条件平均水平速度为 0.42 mm/s。这给第二轮扰动阶段提供了训练前的方向反应基线。 [冻结 CPU 基线](/home/mint/instinctrl-runs/INSTINCT-GPU-R2-U704-MATCHED-HOVER/result.json) · [诊断入口](../../../tools/r6_direct/temporal_probe.py)

另用同一 MID360 波束、半径 0.34 m 的靠近球体和现有 ICS 做固定观测计算。球从 `−X` 逼近，墙在 `+X`，地面垂距 2 m。以 15° 的角度间隔测试 0.25 和 0.46 m/s 的水平指令，统计裁决后仍超过 0.10 m/s 的方向。ICS 使用原研究的 0.15 m 额外净空。第二轮物理闭环的靠墙起点净空为 1.40 m，0.70 m 的墙距用来检查偏离悬停点后的动作余量。 [现有 ICS](../../../isaaclab-training/instinctlab/control/ics.py) · [物理动态评估布置](../../../training_workloads/unified_h1/dynamic_assay.py)
