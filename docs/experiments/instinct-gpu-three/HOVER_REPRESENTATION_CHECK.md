# 零指令下的逼近方向短验证

用第二轮扰动前的 `u704` 和 24 组有可靠逼近线索的 CPU 夹具做了 96 次短监督更新。每组保持最新扫描完全一致，分别保留逼近、静止和远离的过去三帧。只有逼近样本以退向为目标。验证用 24 组未见过的朝向与 8 组未参与训练的管道端面。 [冻结诊断输入与结果](/home/mint/instinctrl-runs/INSTINCT-GPU-HOVER-GATED-DIRECTION-PROBE/result.json)

| 方案 | 未见朝向的退向响应差 | 未见几何的退向响应差 | 两组静止时的平均水平速度 |
| --- | --- | --- | --- |
| 直接监督现有网络 | −0.02 mm/s | −0.01 mm/s | 40.43 / 38.02 mm/s |
| 放大历史测距差再监督 | +0.73 mm/s | +0.93 mm/s | 26.11 / 27.75 mm/s |
| 对连贯逼近方向学习单一增益 | +168.11 mm/s | +167.13 mm/s | 0.43 / 0.41 mm/s |

第三种方案从合法 M4 中提取连贯的逼近方位，对 Beta 动作分布施加有方向的偏置。检测不到线索时偏置为零。同一探针中只更新该增益，保留原 actor 权重。结果说明带方向的结构可以把逼近反应与静止漂移分开。扭转机体、窄通道和同时多源逼近仍需要完整闭环评估。第三轮是否采用以及如何结合执行范围，取决于第二轮真机动力学仿真结果。 [短验证代码](../../../tools/r6_direct/hover_representation_probe.py) · [现有指令可执行范围](HOVER_COMMAND_AUTHORITY.md)
