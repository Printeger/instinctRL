# 三轮全量 GPU 训练

用户目标为三轮连续开发、GPU 全量正式训练、完整评价和经验反馈。每轮执行 Isaac Lab 32 环境、128 次真实 PPO 更新、65,536 条物理训练转换及 5 次模型存档。静态回归执行原始 5 项及 16 个扰动条件，共 193,600 条 GPU 评价转换。CPU 平面第 4 至 8 轮用于研究预研和短验证。每一轮的结果进入下一轮选型，使用精确 commit、输入哈希、独立工作目录和阶段回执，关闭上一作业后才启动下一作业。

第一轮复用同一冻结 u640、扰动课程和训练随机流。训练只通过现有 actor 接口读取合法 M4。在真实 GPU PPO 样本的测距背景上构造相同最新扫描、不同逼近历史的成对测量，监督解码后的速度向量。远离保留指令，逼近减少危险方向速度并给予侧让目标。额外监督中的球体是分析合成观测。第一轮 R6 闭环使用真实 Isaac 原场景。动态物理接触、传感器采样与动作反馈需由后续真实场景独立核验。

后续根据第一轮的硬护栏、跟踪和历史选择性，决定保留或修正方向策略。优先把移动物本身接入真实接触与测距链，再看横穿及悬停行为。保持 actor 只接收批准的 LiDAR/IMU 历史和命令。第二轮与第三轮分别在前一轮证据关闭后冻结。系统盘保留 30 GiB，训练、评价和复核单卡串行。三次全量训练、全量评价并核对后停在审查点。
