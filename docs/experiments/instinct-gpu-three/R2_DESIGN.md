# 第二轮用真实移动物体训练

第一轮的成对合成回波没有带来方向性动作选择，且速度跟踪超出配对容差。第二轮从相同的冻结 u640 开始。移除第一轮的合成成对损失，保持前 64 次更新的原训练配方。后 64 次保留原扰动课程和测量延迟、噪声与丢帧，在部分环境加入由 GPU PhysX 推进的移动球体。 [第一轮复盘](R1_LESSON.md)

冻结对照已完成 7,680 条独立动态预检转换。正面逼近、悬停受逼近、靠墙悬停受逼近各有 8/8 碰撞，其余五类共 0/40。复算核对了实测球心、送达 actor 的近交点和每策略步的 20 次物理接触采样。首次两次预检分别暴露 CUDA kinematic 接口缺失与初始停放几何不符，均以零条完成转换关闭。成功的第三次使用有界刚体速度和地面上方停放。 [动态预检结果](pilot-03/RESULTS.json) · [接口失败](pilot-01/FAILURE.json) · [停放失败](pilot-02/FAILURE.json)

根据预检，训练把持续前飞的 `stop` 环境与正面逼近配对，在 `pulse_hold` 环境训练停令受逼近的撤离。`reverse` 环境保留左右横穿与远离变化。部分环境继续用无移动物体的原课程，靠墙动态布置保留给独立评价。训练球在移动环境中按 9 秒单程往返。奖励用实测刚体运动比较未来短时分离距离与指令偏差，保持原碰撞罚项。悬停正则只在批准的 M4 历史有稳定闭合时放宽。 [训练短验证](DYNAMIC_TRAINING_CHECK.md)

本轮以 128 次 PPO 更新、65,536 条训练转换和五次权重保存为完整预算。完整评估先跑原 R6 的 193,600 条转换，再用新种子在八种动态与静止条件下成对复测候选和冻结对照。重点比较各类碰撞率与净空，以及静止和远离对照上的指令跟踪。本轮同时改变物理暴露、训练奖励与悬停正则，结果可用于评估组合效果。
