# Isaac 动态球体闭环

这是三轮 GPU 任务中的短预检与新增后续评价。GPU 主训练和既有 21 条件的静态回归继续各自结算。动态作业按直接运行契约使用独立预算、目录、前驱关闭回执和源码快照。每个受验模型执行两组 32 环境，每组 120 个策略步。实验前先用原冻结 GPU 第二轮做一遍动态接线预检。

两组合计八种条件。正面逼近、远离和左右横穿使用同一套低速操作者命令。原地悬停和靠墙悬停的移动球与静止通行、静止悬停配对。实际场景约束为 H1 的两面垂直墙，靠墙结果描述该布置。所有首次碰撞和跌落留在原始分母。

每个环境的物体使用真 PhysX 球体碰撞形状和逐物理步运动目标。生成回波时，球心从同一步的 PhysX 变换读回，再求球面最近交点。静态或球体中较近的有效返回进入既有测距链、随后进入 M4。actor 仍只接收到批准的测距、IMU、时间和命令。动态接触用无人机原 ContactSensor 按 20 个子步聚合，区别于用于解释的传感器到球面距离。审计独立重算保存的球面交点、真实送达样本、措施计数、轨迹和分母。
