# 静态场景旋转时的误触发检查

同一最新扫描的短监督试验预先筛选了静止与远离不触发的配对。为检查误触发，追加了保留所有样本的静态与逼近对照。机体中心固定。纯静态门框、柱、墙等几何按每帧实际朝向重算射线，静态和移动输入共享同一组噪声及最近朝向。测试包含 0、0.10 和 ±0.21 rad/s 偏航、1 或 3 cm 测距噪声以及 0 或 0.10 s 采集延迟。每种组合有 60 个静态和 48 个逼近样本。 [前一项短验证](HOVER_REPRESENTATION_CHECK.md) · [本次冻结结果](/home/mint/instinctrl-runs/INSTINCT-GPU-HOVER-STATIC-ROTATION-PROBE/result.json)

按同索引比较历史射线，在 960 个静态样本中误触发 534 次。最差组合经原 ICS 后，新增水平速度的 P99 为 0.265 m/s。静态门框或墙扫过采样角度时，能制造与来物相似的射线距离变化。

用旧扫描角邻域内的最近可信回波作为保守比较值，误触发降至 0/960，保留 762/768 个逼近触发。该做法给小角度错位留出余量，不增加位姿、地图或速度估计输入。预留默认 +30° MID360 安装和既有 ICS。测试是 CPU 解析夹具，未覆盖真实机体旋转时的遮挡、多个方向的相消及复杂物体反射。 [探针代码](../../../tools/r6_direct/hover_noise_probe.py)
