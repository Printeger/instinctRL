# R4 长训与留出评价冻结方案

主要问题是保留已验证的有界侧让选项后，同一起点继续 PPO 能否改善避让后恢复与无威胁跟踪，同时保留由选项带来的前向安全收益。第三轮同权重在前向多次中断，25 步持续性对照使前向碰撞 16/16→0/16。独立的执行层测试把非零前飞逼近碰撞从 8/8 降到 3/8，动态悬停从 8/8 降到 2/8。短测中横穿进度下降约 0.13 m，靠墙悬停仍为 8/8 碰撞。后向留出单列，不以 PPO 增量弥补缺失视场。 [同权重留置](development-02/RESULTS.json) · [共享执行层短测](option-check/RESULTS.json)

候选从冻结 `u640` 恢复 actor、critic、Adam 和计数。用训练种子 `2026112401` 新开独立 RNG 流。保留原始课程前 64 个更新，之后 320 个更新使用含实测移动球体、延迟、丢帧和噪声的配方。动作选项读取相同 M4 送达输入和 IMU，不进入 PPO 隐状态，也不读取真值。训练奖励和 critic 保留原有特权途径。继续使用原 governor、ICS 和底层飞控。

**同一候选计划新增 384 次 PPO 迭代、196,608 条环境转换，32 个环境、每次 16 步。** 训练终点固定为 `u1024`。选择三倍于 R3 的训练量，因为执行层对照已展示前向收益，扩量主要检验学习能否补上跟踪及恢复，保留更多预算用于独立物理留出。各段依次结束于 `u720`、`u768`、`u896`、`u1024`。第一段包含 64 原配方和 16 扰动更新，用实测写入量核对余下三段容量。每段恢复完整网络、Adam、计数、训练种子和 RNG，重建物理状态和短动作记忆。分段末输出固定权重并校验首轮 logp、序列完整性、退出归属和最终计数。已有真实恢复预检走过 `u640→u642→u646`，本次用同一恢复契约和新的配方身份。 [历史恢复预检](../third-training/formal/REPORT.md)

证据布局为 `~/instinctrl-runs/<run-id>/`，单作业普通目录、原日志不覆盖，盘面实时保持 30 GiB。已用 R3 的 64 扰动更新实测约 6.84 GiB 压缩测量和 23.9 GiB 原始测量估算。每个最长 128 更新段预留 20 GiB 压缩证据、2 GiB 其他载荷和 64 GiB 单一日志原始上限。完整同设备概率回放仅消费保存的输入且不训练。单 GPU 串行，前驱回执与标准资源入口有效。

## 冻结比较

- 训练增益对照使用冻结 `u640` 加相同部署选项。旧合格 `instinct-next` R2 权重作为产品基线，保留旧全套 R6 配对原件。只评价最终 `u1024` 作为候选，固定全部布局和种子后一次保留评价。
- 独立物理留出用种子 `1096583497`。每臂 192 个 episode，按 4 类布局各 8 个变体和 6 个行为组组织。房间门洞、稀疏树干、街道缺口和开口管道使用实际射线网格与碰撞网格。开发验证用独立种子 `77162057`。每个行为组固定 120 步，三臂共 69,120 条转换。第 80–119 步固定为恢复跟踪窗。统计每条初始 episode，重置后轨迹不追加到分母。
- 动态门槛为前向悬停和前飞逼近两类合计碰撞相对旧合格基线至少减少一半，且各场景没有把旧合格基线的通过变成碰撞。报告每布局的救回和新增碰撞、轨迹位移及物理接触，后向独立报告。训练增益按加同一选项的起点与终点计算。报告根体到球心距离时标注几何代理。
- 常规门槛为完整 R6 原五项与 16 扰动项全部 32/32，固定块配对跟踪 RMSE 增量 ≤0.010 m/s。留出无威胁普通通行各布局的进度 ≥旧基线 95% 且 ≥1.5 m，跟踪 RMSE 增量 ≤0.010 m/s。留出静止悬停各布局的平均最大水平位移增量 ≤5 mm。前飞避让在固定恢复窗复核跟踪，并报告 12 秒进度占同布局无威胁通行进度的比例，90% 为恢复工程参考。分开评价有威胁时的必要侧让和无威胁时的漂移。
