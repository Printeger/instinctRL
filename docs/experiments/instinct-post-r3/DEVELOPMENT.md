# R3 后的方向持续性物理对照

本轮接续用户 2026-11-24 的研究授权。第三轮前向反应在 4.28 s 窗口内累计只有 1.31 s。首次请求约 0.286 m/s 完整下发，后续触发步平均请求 0.273 m/s、下发 0.183 m/s，横移均值 0.161 m。后向首次有效提示到接触约 1.2 s。 [R3 原件复盘](../instinct-gpu-three/R3_LESSON.md)

开发对照在相同 Isaac PhysX 场地、配对种子及同一 R3 `u768` 权重上，比较原逐帧方向和保留首次可信侧让偏置 25 个策略步。偏置仍在原 Beta logits 上，同一步从获批 IMU 角速率作平面方向补偿。指令离开零位、观测过期或环境重置时立即退出保留，期间每步照常走 governor、ICS 和 Lee。实验不改变传感器安装，也不训练。验证同一权重、真实接触及原始被测回波。

每臂 64 个 episode。32 个前后配对覆盖开阔和靠墙，另 32 个覆盖静止悬停、移动体远离、普通通行和动态悬停。每 episode 最多 120 步，运行总量 15,360 条评价转换。固定首组沿用 R3 视场种子 183421779，供开发归因使用。逐步记录角速率峰值、测距年龄、原始提示、保留偏置、ICS beta、请求与实际下发、机体轨迹和物理接触。

若持有增加固定方向下发积分和机体横移，并使前向至少半数配对从碰撞转为通过，且无新对照碰撞或明显通行悬停退化，再进入非零指令与放大训练候选的短验证。若仍碰撞，先分辨裁决削减和动作实际响应，再决定是否改变可行方向、传感视场或训练方案。
