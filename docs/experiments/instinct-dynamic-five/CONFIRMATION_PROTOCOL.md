# 单次独立确认

选择规则在读取第 8 轮结果前固定。候选先要求开发集安全通行条件零碰撞，并至少保留直通对照 95% 的安全通行进度。合格候选优先比较全部 192 条的碰撞数，随后比较通行碰撞数和安全通行进度。若全部候选不合格，保留最少碰撞者作失效分析。确认完成后保持该选择，逐组报告失败。

确认采用已冻结的不同场景参数和随机流，每类场景及运动组合 12 次，共 288 条完整计分轨迹。比较选中候选、直通、固定降速、几何参考及冻结 R2 投影。确认评价复用同一动作反馈、投影和评分代码。只读第一份完整结果。该评价保留部分不同的参数范围及新随机流，场景族与开发阶段相同。

碰撞仍是阻止候选进入更高保真部署验收的依据。开放道路、树林及管道中的真实飞行需要独立六自由度和实物证据。
