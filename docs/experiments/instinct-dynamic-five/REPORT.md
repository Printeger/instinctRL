# 五轮动态闭环审查点

第 4 至 8 轮均完成开发、正式训练和配对闭环评价。每轮完整训练 16 个 epoch，合计 113,541 条带标签轨迹样本、9,488 次优化、5 份终点权重。每轮使用同一套 192 条开发评价轨迹，末轮依冻结规则选中第 8 轮，另完成一次 288 条确认评价。 [运行与数据清单](EVIDENCE.json) · [确认选择](CONFIRMATION_INPUTS.json)

本批采用 80 步的解析平面动力学和时序测距，覆盖门洞、树干状障碍、街道与管道。策略使用测距历史、有效性、采集时戳、IMU 派生的相对角动及命令。仿真真值用于训练标签和评价，部署输入没有位姿、地图、显式速度估计或障碍真值。原 Isaac 六自由度及 R6 结果保留为独立证据。 [研究计划](PLAN.md)

## 停止点与下步

第 8 轮作为后续研究候选。横穿和狭窄空间悬停的失败仍阻止部署验收。下一步先在冻结的这 8 个失败条件中区分提前量不足、横向运动误判和缺少可行退让动作，再把有效改动放到新的独立条件和 Isaac 六自由度闭环。优先检查横向扫掠占用以及狭窄空间的替代动作，同时保留无干扰悬停和正常通行检查。
