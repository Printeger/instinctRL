# 五轮动态闭环研究

任务为用户授权的连续五轮开发、短验证、完整训练、评价和经验反馈。使用 CPU 解析平面动力学，80 个 0.1 s 决策周期。场景包含门洞、树干状离散障碍、街道和管道。每类交叉六个运动条件，包括无移动物、逼近、远离、横穿、悬停被逼近及无干扰悬停。此研究平台的适用范围是平移闭环、测距时序和操作者意图跟随。Isaac 六自由度、旧 R6 统计和实飞结果分别保留。

策略侧只使用模拟 LiDAR 测距历史、有效性、采集时间、相对角动和命令。几何、坐标及真实速度用于仿真评分和训练标签生成。动力学真值从不进入策略或部署输入。CPU 比较冻结 R2 通过投影 M4、原动作解码和 ICS，附加解析平台的同一扫描保护。操作者直通、固定 0.8 倍降速和训练评分台的几何参考由同一动力学测量。所有碰撞保留在分母，另记连续扫掠净空、固定时限进度、跟踪误差及悬停漂移。

每轮冻结精确源码、训练配置、起点和参考。完整训练使用全部实际生成的闭环样本和注册轮次，留存数据哈希、优化计数、终点权重及完整逐场景评价。训练、开发评价和最终一次确认分开。后续轮可改变方案，选择须引用上一轮的结果。系统盘保留 30 GiB，所有原始输出使用 ~/instinctrl-runs 下普通目录。STOP 检查贯穿各阶段。完整五轮后停止待审。

第一轮新机制以方向性动作模仿替代单边指令缩放。标签来自同一时刻在固定动作集合里比较轨迹净空和意图误差，包括保持安全速度、提前侧让和悬停时离开危险方向。局部速度空间筛选的启发源见原始研究。 [Fiorini 与 Shiller](https://journals.sagepub.com/doi/10.1177/027836499801700706)
