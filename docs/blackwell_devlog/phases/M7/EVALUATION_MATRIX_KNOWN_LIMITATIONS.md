# M7 Evaluation Availability Matrix Known Limitations

- `READY` means accepted evidence permits construction of a later audited run
  plan. It does not mean executed, passed, safe, deployable in all cases or
  performant.
- Only the seven B0 simulator cells backed by accepted fixtures are `READY`.
- B1 is a nondeployable privileged upper bound and has no accepted adapter.
- B2-B7 have no accepted baseline capabilities.
- B8 is optional and has no accepted model-based filter capability.
- The optional dynamic-obstacle row has no accepted fixture or evidence.
- Both required real-robot rows lack accepted access, fixtures and evidence.
- No actor audit was run or claimed; every cell requires
  `PASS_BEFORE_EXECUTION` before any later execution.
- No metrics, thresholds, checkpoints, rankings, comparisons or performance
  claims are present.
- This work does not authorize scenario execution, B1-B8 implementation,
  dynamic/real-robot work, M7/M8 acceptance, training, merge or push.
