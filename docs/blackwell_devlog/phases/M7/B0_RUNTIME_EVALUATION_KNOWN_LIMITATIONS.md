# M7-012 Exact B0 Runtime Evaluation Known Limitations

- Qualification covers one fixed seed and the exact accepted eight-command
  schedule with two environments. It is not a scenario matrix or statistical
  campaign.
- The bounded mode intentionally rejects every reset, done and termination.
  Reset/termination campaigns, partial reset, resume and concurrency remain
  outside this Order.
- Exact observability is wired and valid for all 16 samples, but its recorded
  minimum singular value is zero in this fixed fixture. M7-012 applies no
  observability-performance threshold and makes no geometry-quality claim.
- Tracking, drift, clearance, collision, command-preservation, intervention and
  observability values prove wiring and aggregation only. They are not policy,
  flight-quality, safety, ranking or B0-vs-B1-B8 performance claims.
- Anchor is disabled for B0, so the anchor metric is explicitly unavailable
  with denominator and valid count zero. ICS is disabled with beta one,
  emergency false and zero intervention frequency, as required by the accepted
  formulas.
- The complete independent Torch bundles need not have identical archive-byte
  hashes. Their decoded ordered content, tensor metadata and values are exactly
  equal under the complete comparator.
- No scenario generator, learned B0 actor, normalized governor action,
  checkpoint, optimizer, training, evaluation campaign, M8 or scale run is
  provided or authorized by this work.
