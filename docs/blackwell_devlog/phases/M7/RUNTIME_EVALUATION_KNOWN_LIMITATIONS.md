# Runtime Evaluation Known Limitations

- The fixed freshly initialized actor is an integration stimulus, not a trained policy.
- Exactly two environments and eight policy steps are qualified; no scenario suite,
  policy ranking, convergence, or scale claim is made.
- Observability remains unavailable because no algorithm is authorized.
- Tracking, station, anchor, clearance, collision, and ICS values are diagnostic only.
- One public timeout is covered; the B0-B8 ablation matrix is not implemented.
