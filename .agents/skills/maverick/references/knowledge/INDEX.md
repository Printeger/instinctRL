# 跨学科机制地图

这是通用知识的入口，不是项目事实库，也不是完整学科教材。卡片中的“迁移假设”是本框架提出的设计线索，引用文献只支持原领域机制，不证明新项目中的效果。

| 卡片 | 机制与连接 | 常见问题信号 |
|---|---|---|
| [控制与信息](control-information.md) | 反馈、可观测性、信息量、编码 | 系统看不清状态、干预后振荡、数据多但没有新信息 |
| [网络与物理](networks-physics.md) | 电网络、随机游走、守恒、排队 | 局部约束、传播路径、瓶颈、积压 |
| [生物与适应](biology-adaptation.md) | 反应扩散、结构鲁棒性、局部规则 | 需要自组织、环境变化、调参脆弱 |
| [认知与实验](cognition-experiments.md) | 识别与回忆、外部提示、随机化、混杂 | 使用者费脑、结论归因不清、结果受顺序影响 |

资料按需读取，通常一个邻近机制加一个较远机制已经足够。相同词语不代表相同数学结构。迁移时对应变量、作用关系、边界条件和可观测结果。

项目初始化生成的领域知识应另外记录：术语与单位、具体实现、领域来源、项目约束和未知项。不要用项目知识替换这份地图。当前目录只有起点，新的学科入口可在任务需要时按可信来源补充，不要求每次联网或遍历全部卡片。
